# 第5回 OS：スケジューリングと仮想記憶・ページ置換

> タスクの3つの状態とスケジューリング方式、仮想記憶とページフォールト、FIFOとLRUによるページ置換の違いを学びます。

- 音声: [../audio/ep05_os-virtual-memory.mp3](../audio/ep05_os-virtual-memory.mp3)（約5分12秒）
- 音声合成: VOICEVOX:四国めたん、VOICEVOX:ずんだもん

**四国めたん**：こんにちは、四国めたんよ。第5回は、OSのスケジューリングと仮想記憶を学ぶわ。

**ずんだもん**：ずんだもんなのだ。OSって、パソコンの裏で何をしているのだ？

**四国めたん**：今日は、CPUを誰に使わせるかという話と、メモリを大きく見せる仕組みの話よ。どちらも科目Aの頻出ね。

**四国めたん**：まず、タスクには3つの状態があるの。実行可能状態、実行状態、待ち状態よ。

**四国めたん**：実行可能状態は、CPUさえもらえればすぐ動ける状態。順番待ちの列に並んでいるイメージね。

**四国めたん**：実行状態は、CPUを割り当てられて動いている状態。シングルコアなら1つだけよ。

**四国めたん**：待ち状態は、入出力の完了などを待っていて、CPUがあっても動けない状態ね。

**ずんだもん**：入出力が終わったら、すぐ実行状態に戻れるのだ？

**四国めたん**：そこがひっかけよ。待ち状態から直接、実行状態には行けないの。まず実行可能状態に戻って、順番を待つわ。

**四国めたん**：実行可能なタスクにCPUを割り当てることを、ディスパッチというわ。

**ずんだもん**：どのタスクから順番に動かすのだ？

**四国めたん**：それを決めるのがスケジューリングよ。代表的な方式を4つ紹介するわね。

**四国めたん**：1つ目は到着順。来た順に実行するだけね。

**四国めたん**：2つ目は処理時間順。処理時間の短いものから実行して、平均ターンアラウンドタイムが最小になる方式よ。

**四国めたん**：時刻0に、処理時間6のAと、2のBが同時に来たとしましょう。到着順でAから実行すると、Aが6、Bが8で終わるわ。

**四国めたん**：平均は、6たす8を2で割って7。短いBを先にすると、Bが2、Aが8で終わって、平均は5になるわね。

**ずんだもん**：短い仕事を先に片づけると、みんなの待ち時間が減るのだ。

**四国めたん**：3つ目は優先度順。ただし、優先度の低いタスクがいつまでも動けない、飢餓状態が起こり得るわ。

**四国めたん**：その対策が、待った時間に応じて優先度を上げる、エージングよ。

**四国めたん**：4つ目はラウンドロビン。一定の時間ずつ順番に実行して、終わらなければ列の最後に戻すの。

**ずんだもん**：次は仮想記憶なのだ。仮想って、本物じゃないのだ？

**四国めたん**：補助記憶を使って、実際の主記憶より大きなアドレス空間をプログラムに見せる仕組みよ。

**四国めたん**：主流のページング方式では、固定長のページという単位で管理して、必要なページだけを、主記憶に置くの。

**四国めたん**：参照したページが主記憶にないことを、ページフォールトというわ。このとき補助記憶から読み込むの。

**四国めたん**：主記憶が足りずに、ページの出し入ればかり起きて処理が進まなくなる現象が、スラッシングよ。

**ずんだもん**：主記憶がいっぱいのときは、どのページを追い出すのだ？

**四国めたん**：それがページ置換アルゴリズムね。FIFOは、最も古くに読み込んだページを追い出すの。

**四国めたん**：LRUは、最後に使われてから最も時間が経っている、つまり一番長く使われていないページを追い出すわ。

**四国めたん**：例で比べましょう。ページ枠は3つ。ページを1、2、3の順に読み込み、次に1を参照してヒットしたとするわ。

**四国めたん**：続けてページ4が来ると、枠がいっぱいなので、1つ追い出す必要があるわね。

**四国めたん**：FIFOなら、読み込んだのが一番古い1を追い出すの。さっき使ったばかりでも関係ないわ。

**四国めたん**：LRUなら、1は直前に使ったので新しい扱い。一番長く使われていない2を追い出すわ。

**ずんだもん**：FIFOは読み込んだ順番だけ、LRUは最後に使った順番で考えるのだ！

**四国めたん**：そのとおり。ヒットしたときに順番を更新するかどうかが、2つの違いよ。

**四国めたん**：ひっかけ注意。FIFOでは、ページ枠を増やしたのにページフォールトが増えることがあるの。ビレイディの異常というわ。

**四国めたん**：ではミニクイズ。第1問。待ち状態のタスクの入出力が完了したら、次はどの状態になるかしら？

*（3秒 考えてみよう）*

**四国めたん**：正解は実行可能状態。直接、実行状態にはならないわ。

**四国めたん**：第2問。ページ枠3つに、ページ2、5、7の順で読み込み、そのあと2を参照したわ。

**四国めたん**：次にページ9が来たとき、LRUで追い出されるのはどのページかしら？

*（4秒 考えてみよう）*

**ずんだもん**：2はさっき使ったから残るのだ。一番長く使われていないのは5なのだ！

**四国めたん**：正解よ。もしFIFOなら、一番古く読み込んだ2が追い出されるわね。

**四国めたん**：第3問。スラッシングの対策を1つ答えて。

*（3秒 考えてみよう）*

**四国めたん**：正解は、主記憶を増やすこと。または、同時に実行するプログラムの数、つまり多重度を減らすことよ。

**四国めたん**：まとめよ。一つ目。タスクは実行可能、実行、待ちの3状態。待ちから実行へは直接行けない。

**四国めたん**：二つ目。処理時間順は平均ターンアラウンドタイムが最小。優先度順の飢餓状態はエージングで防ぐ。

**四国めたん**：三つ目。FIFOは一番古く読み込んだページ、LRUは一番長く使われていないページを追い出す。

**ずんだもん**：OSの裏方の仕事が、ちょっと分かったのだ！

**四国めたん**：次回は、データベースの正規化とSQLよ。またね。
