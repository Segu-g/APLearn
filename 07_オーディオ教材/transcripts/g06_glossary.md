# 用語聞き流し6 情報セキュリティ

> 情報セキュリティの頻出略語41語を、略語 → 間 → 正式名称と意味の順に読み上げます。

- 音声: [../audio/g06_glossary.mp3](../audio/g06_glossary.mp3)（約6分38秒）
- 音声合成: VOICEVOX:春日部つむぎ、VOICEVOX:冥鳴ひまり

**春日部つむぎ**：用語の聞き流し、情報セキュリティ編だよ！

**冥鳴ひまり**：略語を読んだら、少しだけ間をあけますね。意味を思い浮かべてから、答えを聞いてください。

**冥鳴ひまり**：CIA。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Confidentiality, Integrity, Availability。

**春日部つむぎ**：機密性・完全性・可用性。情報セキュリティの3要素

**冥鳴ひまり**：ISMS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Information Security Management System。

**春日部つむぎ**：情報セキュリティマネジメントシステム（JIS Q 27001）

**冥鳴ひまり**：CSIRT。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Computer Security Incident Response Team。

**春日部つむぎ**：セキュリティインシデントに対応する組織

**冥鳴ひまり**：SOC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Security Operation Center。

**春日部つむぎ**：セキュリティ機器を24時間監視・分析する組織

**冥鳴ひまり**：PKI。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Public Key Infrastructure。

**春日部つむぎ**：公開鍵基盤。認証局が証明書で公開鍵の正当性を保証

**冥鳴ひまり**：CA。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Certificate Authority。

**春日部つむぎ**：認証局。デジタル証明書を発行する

**冥鳴ひまり**：CRL。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Certificate Revocation List。

**春日部つむぎ**：失効したデジタル証明書の一覧

**冥鳴ひまり**：OCSP。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Online Certificate Status Protocol。

**春日部つむぎ**：証明書の失効状態をオンラインで確認する

**冥鳴ひまり**：TLS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Transport Layer Security。

**春日部つむぎ**：通信の暗号化・サーバ認証を行うプロトコル（SSLの後継）

**冥鳴ひまり**：AES。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Advanced Encryption Standard。

**春日部つむぎ**：代表的な共通鍵暗号

**冥鳴ひまり**：RSA。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Rivest-Shamir-Adleman。

**春日部つむぎ**：素因数分解の困難性を利用した公開鍵暗号

**冥鳴ひまり**：ECC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Elliptic Curve Cryptography。

**春日部つむぎ**：楕円曲線暗号。短い鍵長で高い安全性

**冥鳴ひまり**：SHA-256。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Secure Hash Algorithm 256。

**春日部つむぎ**：256ビットのハッシュ値を出力するハッシュ関数

**冥鳴ひまり**：MAC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Message Authentication Code。

**春日部つむぎ**：メッセージ認証符号。改ざん検知に使う（ネットワークのMACとは別）

**冥鳴ひまり**：HMAC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Hash-based MAC。

**春日部つむぎ**：ハッシュ関数と共通鍵を使うメッセージ認証符号

**冥鳴ひまり**：MFA。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Multi-Factor Authentication。

**春日部つむぎ**：多要素認証（知識・所持・生体のうち2つ以上）

**冥鳴ひまり**：OTP。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：One-Time Password。

**春日部つむぎ**：一度しか使えないパスワード

**冥鳴ひまり**：SSO。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Single Sign-On。

**春日部つむぎ**：一度の認証で複数システムを利用できる仕組み

**冥鳴ひまり**：SAML。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Security Assertion Markup Language。

**春日部つむぎ**：SSOで認証情報をやり取りするXMLベースの標準

**冥鳴ひまり**：IDS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Intrusion Detection System。

**春日部つむぎ**：侵入検知システム。不正な通信を検知・通知する

**冥鳴ひまり**：IPS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Intrusion Prevention System。

**春日部つむぎ**：侵入防止システム。不正な通信を検知して遮断する

**冥鳴ひまり**：WAF。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Web Application Firewall。

**春日部つむぎ**：Webアプリへの攻撃（SQLインジェクション等）を防ぐ

**冥鳴ひまり**：UTM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Unified Threat Management。

**春日部つむぎ**：FW・IPS・ウイルス対策などを1台に統合した機器

**冥鳴ひまり**：EDR。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Endpoint Detection and Response。

**春日部つむぎ**：端末の挙動を監視し、侵害の検知・対応を行う

**冥鳴ひまり**：SIEM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Security Information and Event Management。

**春日部つむぎ**：各種ログを集約・相関分析して脅威を検知する

**冥鳴ひまり**：DMZ。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：DeMilitarized Zone。

**春日部つむぎ**：外部公開サーバを置く、内部LANと外部の中間セグメント

**冥鳴ひまり**：DoS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Denial of Service。

**春日部つむぎ**：大量の要求でサービスを妨害する攻撃

**冥鳴ひまり**：DDoS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Distributed DoS。

**春日部つむぎ**：多数の機器から同時に行うDoS攻撃

**冥鳴ひまり**：XSS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Cross-Site Scripting。

**春日部つむぎ**：悪意のあるスクリプトを他の利用者のブラウザで実行させる攻撃

**冥鳴ひまり**：CSRF。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Cross-Site Request Forgery。

**春日部つむぎ**：利用者に意図しないリクエストを送信させる攻撃

**冥鳴ひまり**：APT。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Advanced Persistent Threat。

**春日部つむぎ**：特定組織を長期間狙う高度な標的型攻撃

**冥鳴ひまり**：BEC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Business Email Compromise。

**春日部つむぎ**：ビジネスメール詐欺。取引先等を装い送金させる

**冥鳴ひまり**：SPF。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Sender Policy Framework。

**春日部つむぎ**：送信元メールサーバのIPアドレスをDNSで検証する

**冥鳴ひまり**：DKIM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：DomainKeys Identified Mail。

**春日部つむぎ**：メールにデジタル署名を付けて送信ドメインを検証する

**冥鳴ひまり**：DMARC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Domain-based Message Authentication, Reporting and Conformance。

**春日部つむぎ**：SPF/DKIMの検証結果に基づく処理方針を送信側が宣言する

**冥鳴ひまり**：S/MIME。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Secure/Multipurpose Internet Mail Extensions。

**春日部つむぎ**：公開鍵暗号によるメールの暗号化・署名

**冥鳴ひまり**：WPA3。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Wi-Fi Protected Access 3。

**春日部つむぎ**：無線LANの暗号化・認証規格

**冥鳴ひまり**：CVE。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Common Vulnerabilities and Exposures。

**春日部つむぎ**：脆弱性に付けられる共通の識別番号

**冥鳴ひまり**：CVSS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Common Vulnerability Scoring System。

**春日部つむぎ**：脆弱性の深刻度を評価する共通の基準

**冥鳴ひまり**：TPM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Trusted Platform Module。

**春日部つむぎ**：鍵の生成・保管を行う耐タンパ性のあるチップ

**冥鳴ひまり**：NISC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：National center of Incident readiness and Strategy for Cybersecurity。

**春日部つむぎ**：内閣サイバーセキュリティセンター（2025年7月に国家サイバー統括室へ改組）

**冥鳴ひまり**：情報セキュリティ編は、ここまでです。聞き取れなかった用語は、略語カードで復習しましょうね。
