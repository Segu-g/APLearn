# 用語聞き流し6 情報セキュリティ

> 情報セキュリティの頻出略語41語を、略語 → 間 → 正式名称と意味の順に読み上げます。

- 音声: [../audio/g06_glossary.mp3](../audio/g06_glossary.mp3)（約7分20秒）
- 音声合成: VOICEVOX:四国めたん、VOICEVOX:ずんだもん

**ずんだもん**：用語の聞き流し、情報セキュリティ編なのだ。

**四国めたん**：略語を読み上げたら、少し間をあけるわね。意味を思い浮かべてから答えを聞いてね。

**四国めたん**：CIA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Confidentiality, Integrity, Availability。

**ずんだもん**：機密性・完全性・可用性。情報セキュリティの3要素

**四国めたん**：ISMS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Information Security Management System。

**ずんだもん**：情報セキュリティマネジメントシステム（JIS Q 27001）

**四国めたん**：CSIRT。

*（1.5秒 考えてみよう）*

**ずんだもん**：Computer Security Incident Response Team。

**ずんだもん**：セキュリティインシデントに対応する組織

**四国めたん**：SOC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Security Operation Center。

**ずんだもん**：セキュリティ機器を24時間監視・分析する組織

**四国めたん**：PKI。

*（1.5秒 考えてみよう）*

**ずんだもん**：Public Key Infrastructure。

**ずんだもん**：公開鍵基盤。認証局が証明書で公開鍵の正当性を保証

**四国めたん**：CA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Certificate Authority。

**ずんだもん**：認証局。デジタル証明書を発行する

**四国めたん**：CRL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Certificate Revocation List。

**ずんだもん**：失効したデジタル証明書の一覧

**四国めたん**：OCSP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Online Certificate Status Protocol。

**ずんだもん**：証明書の失効状態をオンラインで確認する

**四国めたん**：TLS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Transport Layer Security。

**ずんだもん**：通信の暗号化・サーバ認証を行うプロトコル（SSLの後継）

**四国めたん**：AES。

*（1.5秒 考えてみよう）*

**ずんだもん**：Advanced Encryption Standard。

**ずんだもん**：代表的な共通鍵暗号

**四国めたん**：RSA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Rivest-Shamir-Adleman。

**ずんだもん**：素因数分解の困難性を利用した公開鍵暗号

**四国めたん**：ECC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Elliptic Curve Cryptography。

**ずんだもん**：楕円曲線暗号。短い鍵長で高い安全性

**四国めたん**：SHA-256。

*（1.5秒 考えてみよう）*

**ずんだもん**：Secure Hash Algorithm 256。

**ずんだもん**：256ビットのハッシュ値を出力するハッシュ関数

**四国めたん**：MAC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Message Authentication Code。

**ずんだもん**：メッセージ認証符号。改ざん検知に使う（ネットワークのMACとは別）

**四国めたん**：HMAC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Hash-based MAC。

**ずんだもん**：ハッシュ関数と共通鍵を使うメッセージ認証符号

**四国めたん**：MFA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Multi-Factor Authentication。

**ずんだもん**：多要素認証（知識・所持・生体のうち2つ以上）

**四国めたん**：OTP。

*（1.5秒 考えてみよう）*

**ずんだもん**：One-Time Password。

**ずんだもん**：一度しか使えないパスワード

**四国めたん**：SSO。

*（1.5秒 考えてみよう）*

**ずんだもん**：Single Sign-On。

**ずんだもん**：一度の認証で複数システムを利用できる仕組み

**四国めたん**：SAML。

*（1.5秒 考えてみよう）*

**ずんだもん**：Security Assertion Markup Language。

**ずんだもん**：SSOで認証情報をやり取りするXMLベースの標準

**四国めたん**：IDS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Intrusion Detection System。

**ずんだもん**：侵入検知システム。不正な通信を検知・通知する

**四国めたん**：IPS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Intrusion Prevention System。

**ずんだもん**：侵入防止システム。不正な通信を検知して遮断する

**四国めたん**：WAF。

*（1.5秒 考えてみよう）*

**ずんだもん**：Web Application Firewall。

**ずんだもん**：Webアプリへの攻撃（SQLインジェクション等）を防ぐ

**四国めたん**：UTM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Unified Threat Management。

**ずんだもん**：FW・IPS・ウイルス対策などを1台に統合した機器

**四国めたん**：EDR。

*（1.5秒 考えてみよう）*

**ずんだもん**：Endpoint Detection and Response。

**ずんだもん**：端末の挙動を監視し、侵害の検知・対応を行う

**四国めたん**：SIEM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Security Information and Event Management。

**ずんだもん**：各種ログを集約・相関分析して脅威を検知する

**四国めたん**：DMZ。

*（1.5秒 考えてみよう）*

**ずんだもん**：DeMilitarized Zone。

**ずんだもん**：外部公開サーバを置く、内部LANと外部の中間セグメント

**四国めたん**：DoS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Denial of Service。

**ずんだもん**：大量の要求でサービスを妨害する攻撃

**四国めたん**：DDoS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Distributed DoS。

**ずんだもん**：多数の機器から同時に行うDoS攻撃

**四国めたん**：XSS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Cross-Site Scripting。

**ずんだもん**：悪意のあるスクリプトを他の利用者のブラウザで実行させる攻撃

**四国めたん**：CSRF。

*（1.5秒 考えてみよう）*

**ずんだもん**：Cross-Site Request Forgery。

**ずんだもん**：利用者に意図しないリクエストを送信させる攻撃

**四国めたん**：APT。

*（1.5秒 考えてみよう）*

**ずんだもん**：Advanced Persistent Threat。

**ずんだもん**：特定組織を長期間狙う高度な標的型攻撃

**四国めたん**：BEC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Business Email Compromise。

**ずんだもん**：ビジネスメール詐欺。取引先等を装い送金させる

**四国めたん**：SPF。

*（1.5秒 考えてみよう）*

**ずんだもん**：Sender Policy Framework。

**ずんだもん**：送信元メールサーバのIPアドレスをDNSで検証する

**四国めたん**：DKIM。

*（1.5秒 考えてみよう）*

**ずんだもん**：DomainKeys Identified Mail。

**ずんだもん**：メールにデジタル署名を付けて送信ドメインを検証する

**四国めたん**：DMARC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Domain-based Message Authentication, Reporting and Conformance。

**ずんだもん**：SPF/DKIMの検証結果に基づく処理方針を送信側が宣言する

**四国めたん**：S/MIME。

*（1.5秒 考えてみよう）*

**ずんだもん**：Secure/Multipurpose Internet Mail Extensions。

**ずんだもん**：公開鍵暗号によるメールの暗号化・署名

**四国めたん**：WPA3。

*（1.5秒 考えてみよう）*

**ずんだもん**：Wi-Fi Protected Access 3。

**ずんだもん**：無線LANの暗号化・認証規格

**四国めたん**：CVE。

*（1.5秒 考えてみよう）*

**ずんだもん**：Common Vulnerabilities and Exposures。

**ずんだもん**：脆弱性に付けられる共通の識別番号

**四国めたん**：CVSS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Common Vulnerability Scoring System。

**ずんだもん**：脆弱性の深刻度を評価する共通の基準

**四国めたん**：TPM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Trusted Platform Module。

**ずんだもん**：鍵の生成・保管を行う耐タンパ性のあるチップ

**四国めたん**：NISC。

*（1.5秒 考えてみよう）*

**ずんだもん**：National center of Incident readiness and Strategy for Cybersecurity。

**ずんだもん**：内閣サイバーセキュリティセンター（2025年7月に国家サイバー統括室へ改組）

**四国めたん**：情報セキュリティ編は、ここまでよ。聞き取れなかった用語は、略語カードで復習してね。
