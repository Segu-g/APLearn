# 用語聞き流し2 コンピュータ構成要素・ハードウェア

**春日部つむぎ**：用語の聞き流し、コンピュータ構成要素・ハードウェア編だよ！

**冥鳴ひまり**：略語を読んだら、少しだけ間をあけますね。意味を思い浮かべてから、答えを聞いてください。

**冥鳴ひまり**：CPU。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Central Processing Unit。

**春日部つむぎ**：中央処理装置。命令を解読・実行する

**冥鳴ひまり**：GPU。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Graphics Processing Unit。

**春日部つむぎ**：画像処理装置。並列計算に強くAI学習にも使う

**冥鳴ひまり**：ALU。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Arithmetic Logic Unit。

**春日部つむぎ**：算術論理演算装置。CPU内で演算を行う

**冥鳴ひまり**：CPI。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Cycles Per Instruction。

**春日部つむぎ**：1命令の実行に必要な平均クロック数

**冥鳴ひまり**：MIPS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Million Instructions Per Second。

**春日部つむぎ**：1秒間に実行できる命令数（百万単位）

**冥鳴ひまり**：FLOPS。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：FLoating-point Operations Per Second。

**春日部つむぎ**：1秒間の浮動小数点演算回数

**冥鳴ひまり**：RISC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Reduced Instruction Set Computer。

**春日部つむぎ**：命令を単純・固定長にしてパイプラインを効率化したCPU

**冥鳴ひまり**：CISC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Complex Instruction Set Computer。

**春日部つむぎ**：複雑で可変長の命令を多く持つCPU

**冥鳴ひまり**：SIMD。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Single Instruction Multiple Data。

**春日部つむぎ**：1命令で複数データを同時処理する並列方式

**冥鳴ひまり**：DMA。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Direct Memory Access。

**春日部つむぎ**：CPUを介さず装置とメモリ間で直接データ転送する方式

**冥鳴ひまり**：DRAM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Dynamic Random Access Memory。

**春日部つむぎ**：リフレッシュが必要なメモリ。主記憶に使う

**冥鳴ひまり**：SRAM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Static Random Access Memory。

**春日部つむぎ**：リフレッシュ不要で高速なメモリ。キャッシュに使う

**冥鳴ひまり**：ROM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Read Only Memory。

**春日部つむぎ**：読出し専用メモリ（不揮発）

**冥鳴ひまり**：SSD。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Solid State Drive。

**春日部つむぎ**：フラッシュメモリを使った補助記憶装置

**冥鳴ひまり**：HDD。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Hard Disk Drive。

**春日部つむぎ**：磁気ディスク装置

**冥鳴ひまり**：ECC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Error Correcting Code。

**春日部つむぎ**：誤り訂正符号。メモリの1ビット誤りを訂正する

**冥鳴ひまり**：FPGA。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Field Programmable Gate Array。

**春日部つむぎ**：利用者が回路構成を書き換えられる集積回路

**冥鳴ひまり**：SoC。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：System on a Chip。

**春日部つむぎ**：1つのチップにシステムの主要機能を集積したもの

**冥鳴ひまり**：USB。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Universal Serial Bus。

**春日部つむぎ**：周辺機器接続用のシリアルインタフェース

**冥鳴ひまり**：PWM。

*（1.5秒 考えてみよう）*

**春日部つむぎ**：Pulse Width Modulation。

**春日部つむぎ**：パルス幅変調。モータ速度やLED輝度の制御に使う

**冥鳴ひまり**：コンピュータ構成要素・ハードウェア編は、ここまでです。聞き取れなかった用語は、略語カードで復習しましょうね。
