# 用語聞き流し2 コンピュータ構成要素・ハードウェア

> コンピュータ構成要素・ハードウェアの頻出略語20語を、略語 → 間 → 正式名称と意味の順に読み上げます。

- 音声: [../audio/g02_glossary.mp3](../audio/g02_glossary.mp3)（約3分26秒）
- 音声合成: VOICEVOX:四国めたん、VOICEVOX:ずんだもん

**ずんだもん**：用語の聞き流し、コンピュータ構成要素・ハードウェア編なのだ。

**四国めたん**：略語を読み上げたら、少し間をあけるわね。意味を思い浮かべてから答えを聞いてね。

**四国めたん**：CPU。

*（1.5秒 考えてみよう）*

**ずんだもん**：Central Processing Unit。

**ずんだもん**：中央処理装置。命令を解読・実行する

**四国めたん**：GPU。

*（1.5秒 考えてみよう）*

**ずんだもん**：Graphics Processing Unit。

**ずんだもん**：画像処理装置。並列計算に強くAI学習にも使う

**四国めたん**：ALU。

*（1.5秒 考えてみよう）*

**ずんだもん**：Arithmetic Logic Unit。

**ずんだもん**：算術論理演算装置。CPU内で演算を行う

**四国めたん**：CPI。

*（1.5秒 考えてみよう）*

**ずんだもん**：Cycles Per Instruction。

**ずんだもん**：1命令の実行に必要な平均クロック数

**四国めたん**：MIPS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Million Instructions Per Second。

**ずんだもん**：1秒間に実行できる命令数（百万単位）

**四国めたん**：FLOPS。

*（1.5秒 考えてみよう）*

**ずんだもん**：FLoating-point Operations Per Second。

**ずんだもん**：1秒間の浮動小数点演算回数

**四国めたん**：RISC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Reduced Instruction Set Computer。

**ずんだもん**：命令を単純・固定長にしてパイプラインを効率化したCPU

**四国めたん**：CISC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Complex Instruction Set Computer。

**ずんだもん**：複雑で可変長の命令を多く持つCPU

**四国めたん**：SIMD。

*（1.5秒 考えてみよう）*

**ずんだもん**：Single Instruction Multiple Data。

**ずんだもん**：1命令で複数データを同時処理する並列方式

**四国めたん**：DMA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Direct Memory Access。

**ずんだもん**：CPUを介さず装置とメモリ間で直接データ転送する方式

**四国めたん**：DRAM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Dynamic Random Access Memory。

**ずんだもん**：リフレッシュが必要なメモリ。主記憶に使う

**四国めたん**：SRAM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Static Random Access Memory。

**ずんだもん**：リフレッシュ不要で高速なメモリ。キャッシュに使う

**四国めたん**：ROM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Read Only Memory。

**ずんだもん**：読出し専用メモリ（不揮発）

**四国めたん**：SSD。

*（1.5秒 考えてみよう）*

**ずんだもん**：Solid State Drive。

**ずんだもん**：フラッシュメモリを使った補助記憶装置

**四国めたん**：HDD。

*（1.5秒 考えてみよう）*

**ずんだもん**：Hard Disk Drive。

**ずんだもん**：磁気ディスク装置

**四国めたん**：ECC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Error Correcting Code。

**ずんだもん**：誤り訂正符号。メモリの1ビット誤りを訂正する

**四国めたん**：FPGA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Field Programmable Gate Array。

**ずんだもん**：利用者が回路構成を書き換えられる集積回路

**四国めたん**：SoC。

*（1.5秒 考えてみよう）*

**ずんだもん**：System on a Chip。

**ずんだもん**：1つのチップにシステムの主要機能を集積したもの

**四国めたん**：USB。

*（1.5秒 考えてみよう）*

**ずんだもん**：Universal Serial Bus。

**ずんだもん**：周辺機器接続用のシリアルインタフェース

**四国めたん**：PWM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Pulse Width Modulation。

**ずんだもん**：パルス幅変調。モータ速度やLED輝度の制御に使う

**四国めたん**：コンピュータ構成要素・ハードウェア編は、ここまでよ。聞き取れなかった用語は、略語カードで復習してね。
