# 第19回 論理演算・確率・待ち行列

> AND・OR・XORとビットマスク、シフト演算、ド・モルガンの法則、場合の数と確率、M/M/1待ち行列の利用率・待ち時間・応答時間の計算を学びます。

**四国めたん**：こんにちは、四国めたんよ。第19回は、論理演算、確率、そして待ち行列を学ぶわ。

**ずんだもん**：ずんだもんなのだ。数学っぽい回なのだ。ちょっと身構えるのだ。

**四国めたん**：どれも公式は少なくて、型を覚えれば確実に取れる計算よ。順番にいきましょう。

**四国めたん**：まず論理演算。ANDは両方が1のときだけ1。ORはどちらかが1なら1。

**四国めたん**：XORは、排他的論理和。2つが異なるときに1、同じなら0になるわ。

**ずんだもん**：それが試験でどう役に立つのだ？

**四国めたん**：ビットマスクで使うの。特定のビットを取り出したいときは、取り出したいところだけ1にしたマスクとANDをとるわ。

**四国めたん**：マスクが0のところは、相手が何でも0になる。マスクが1のところだけ、元のビットがそのまま残るのね。

**四国めたん**：特定のビットを1にしたいならOR。反転したいならXORよ。どちらも、変えたいところを1にしたマスクを使うわ。

**ずんだもん**：取り出すのはAND、1にするのはOR、ひっくり返すのはXOR、なのだ。

**四国めたん**：完璧ね。XORには、同じマスクで2回とると元に戻る、という性質もあるわ。簡単な暗号やパリティ計算に使うの。

**四国めたん**：次はシフト演算。2進数を左に1ビットずらすと2倍、右に1ビットずらすと半分になるわ。

**四国めたん**：これで掛け算が作れるの。xを10倍したいなら、10xは8xたす2x。

**四国めたん**：つまり、xを左に3ビットずらしたものと、左に1ビットずらしたものを足せばいいわ。

**四国めたん**：ひっかけ注意。符号付きの数を右にずらす算術シフトでは、空いた左側に符号ビットと同じものを入れるの。

**ずんだもん**：ド・モルガンの法則も、よく聞くのだ。

**四国めたん**：「AまたはB」を否定すると、「Aでない、かつ、Bでない」になる。「AかつB」を否定すると、「Aでない、または、Bでない」よ。

**四国めたん**：否定をかっこの中に配ると、「または」と「かつ」が入れ替わる、と覚えればいいわ。

**四国めたん**：集合の人数の問題もあるの。受講者100人で、Python経験者60人、Java経験者45人、どちらも未経験が15人。両方の経験者は？

**四国めたん**：どちらかの経験者は、100ひく15で85人。60たす45は105だから、重なった分は105ひく85で、20人よ。

**ずんだもん**：足しすぎた分が、両方の人なのだ。

**四国めたん**：次は確率。赤玉3個と白玉2個の袋から、同時に2個取り出して、2個とも赤になる確率を考えましょう。

**四国めたん**：5個から2個を選ぶ組合せは、5かける4を2で割って10通り。赤3個から2個を選ぶのは3通り。だから10分の3よ。

**四国めたん**：1個ずつ考えてもいいわ。1個目が赤の確率は5分の3、2個目も赤は4分の2。掛けると、やはり10分の3ね。

**ずんだもん**：並べる順番を区別しないのが、組合せなのだ。

**ずんだもん**：待ち行列って、レジの行列のことなのだ？

**四国めたん**：そうよ。試験で使うのはM/M/1モデル。客はランダムに来て、処理時間もばらつき、窓口は1つ、という前提ね。

**四国めたん**：まず利用率。平均の処理時間を、平均の到着間隔で割るの。窓口が働いている時間の割合よ。

**四国めたん**：次に、利用率を、1ひく利用率で割る。この数に処理時間を掛けると、平均待ち時間になるわ。

**四国めたん**：待ち時間に処理時間を足したものが、平均応答時間よ。

**四国めたん**：例題。客が平均5分おきに来て、1人の処理に平均4分かかる窓口。利用率は4割る5で、0.8。

**四国めたん**：0.8を、1ひく0.8の0.2で割ると4。待ち時間は、4かける処理時間の4分で、16分。応答時間は、それに4分を足して20分よ。

**ずんだもん**：4分の処理なのに、16分も待つのだ！？

**四国めたん**：そう。利用率が1に近づくと、待ち時間は急に増えるの。利用率0.5なら処理時間と同じだけ待つけれど、0.9なら9倍も待つわ。

**四国めたん**：ひっかけ注意。問題が聞いているのが「待ち時間」か「応答時間」かを確認して。応答時間なら処理時間を足し忘れないことよ。

**四国めたん**：ではミニクイズ。第1問。ある8ビットのデータから、下位4ビットだけを取り出したい。使う演算は何かしら？

*（3秒 考えてみよう）*

**四国めたん**：正解はAND。下位4ビットだけを1にしたマスクと、ANDをとるわ。

**四国めたん**：第2問。M/M/1で、平均到着間隔が4分、平均処理時間が2分。平均応答時間は何分？

*（4秒 考えてみよう）*

**ずんだもん**：利用率は2割る4で0.5。0.5を0.5で割って1。待ち時間は2分で、処理の2分を足して4分なのだ！

**四国めたん**：正解よ。

**四国めたん**：第3問。「AかつB」の否定は、ド・モルガンの法則でどうなる？

*（3秒 考えてみよう）*

**四国めたん**：正解は「Aでない、または、Bでない」。「かつ」が「または」に入れ替わるわ。

**四国めたん**：まとめよ。一つ目。取り出すのはAND、1にするのはOR、反転はXOR。左シフトは2倍、右シフトは半分。

**四国めたん**：二つ目。ド・モルガンは、否定を配ると「かつ」と「または」が入れ替わる。組合せは順番を区別しない。

**四国めたん**：三つ目。M/M/1は、利用率を、1ひく利用率で割り、処理時間を掛けて待ち時間。足して応答時間。

**ずんだもん**：混んでいる窓口が、急に待たされる理由が分かったのだ！
