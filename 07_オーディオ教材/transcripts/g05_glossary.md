# 用語聞き流し5 ネットワーク

> ネットワークの頻出略語36語を、略語 → 間 → 正式名称と意味の順に読み上げます。

- 音声: [../audio/g05_glossary.mp3](../audio/g05_glossary.mp3)（約5分58秒）
- 音声合成: VOICEVOX:四国めたん、VOICEVOX:ずんだもん

**ずんだもん**：用語の聞き流し、ネットワーク編なのだ。

**四国めたん**：略語を読み上げたら、少し間をあけるわね。意味を思い浮かべてから答えを聞いてね。

**四国めたん**：OSI。

*（1.5秒 考えてみよう）*

**ずんだもん**：Open Systems Interconnection。

**ずんだもん**：通信機能を7階層に分けた参照モデル

**四国めたん**：TCP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Transmission Control Protocol。

**ずんだもん**：コネクション型で信頼性のあるトランスポート層プロトコル

**四国めたん**：UDP。

*（1.5秒 考えてみよう）*

**ずんだもん**：User Datagram Protocol。

**ずんだもん**：コネクションレスで高速なトランスポート層プロトコル

**四国めたん**：IP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Internet Protocol。

**ずんだもん**：ネットワーク層でパケットの経路制御・アドレス付けを行う

**四国めたん**：IPv6。

*（1.5秒 考えてみよう）*

**ずんだもん**：Internet Protocol version 6。

**ずんだもん**：128ビットのIPアドレスを使う次世代IP

**四国めたん**：ARP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Address Resolution Protocol。

**ずんだもん**：IPアドレスからMACアドレスを求める

**四国めたん**：MAC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Media Access Control。

**ずんだもん**：データリンク層の制御。MACアドレスは機器固有の48ビット番号

**四国めたん**：ICMP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Internet Control Message Protocol。

**ずんだもん**：エラー通知や疎通確認（ping）に使う

**四国めたん**：DNS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Domain Name System。

**ずんだもん**：ドメイン名とIPアドレスを対応づける

**四国めたん**：DHCP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Dynamic Host Configuration Protocol。

**ずんだもん**：IPアドレス等を自動で割り当てる

**四国めたん**：NAT。

*（1.5秒 考えてみよう）*

**ずんだもん**：Network Address Translation。

**ずんだもん**：プライベートIPとグローバルIPを1対1で変換

**四国めたん**：NAPT。

*（1.5秒 考えてみよう）*

**ずんだもん**：Network Address Port Translation。

**ずんだもん**：ポート番号も使い、1つのグローバルIPを複数端末で共有

**四国めたん**：HTTP。

*（1.5秒 考えてみよう）*

**ずんだもん**：HyperText Transfer Protocol。

**ずんだもん**：Webの通信プロトコル（ポート80）

**四国めたん**：HTTPS。

*（1.5秒 考えてみよう）*

**ずんだもん**：HTTP over TLS。

**ずんだもん**：TLSで暗号化したHTTP（ポート443）

**四国めたん**：SMTP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Simple Mail Transfer Protocol。

**ずんだもん**：メールの送信・転送（ポート25、投稿用は587）

**四国めたん**：POP3。

*（1.5秒 考えてみよう）*

**ずんだもん**：Post Office Protocol version 3。

**ずんだもん**：メールをサーバから受信してダウンロードする

**四国めたん**：IMAP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Internet Message Access Protocol。

**ずんだもん**：メールをサーバ上に置いたまま管理する

**四国めたん**：FTP。

*（1.5秒 考えてみよう）*

**ずんだもん**：File Transfer Protocol。

**ずんだもん**：ファイル転送（データ転送20番、制御21番ポート）

**四国めたん**：SSH。

*（1.5秒 考えてみよう）*

**ずんだもん**：Secure SHell。

**ずんだもん**：暗号化された遠隔ログイン（ポート22）

**四国めたん**：NTP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Network Time Protocol。

**ずんだもん**：時刻同期

**四国めたん**：SNMP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Simple Network Management Protocol。

**ずんだもん**：ネットワーク機器の監視・管理

**四国めたん**：VLAN。

*（1.5秒 考えてみよう）*

**ずんだもん**：Virtual LAN。

**ずんだもん**：物理構成によらず論理的にLANを分割する

**四国めたん**：VPN。

*（1.5秒 考えてみよう）*

**ずんだもん**：Virtual Private Network。

**ずんだもん**：公衆網上に暗号化した仮想的な専用線をつくる

**四国めたん**：VRRP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Virtual Router Redundancy Protocol。

**ずんだもん**：複数ルータで仮想ルータをつくり冗長化する

**四国めたん**：OSPF。

*（1.5秒 考えてみよう）*

**ずんだもん**：Open Shortest Path First。

**ずんだもん**：コスト（リンク状態）に基づく経路制御プロトコル

**四国めたん**：BGP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Border Gateway Protocol。

**ずんだもん**：組織（AS）間の経路制御プロトコル

**四国めたん**：CIDR。

*（1.5秒 考えてみよう）*

**ずんだもん**：Classless Inter-Domain Routing。

**ずんだもん**：クラスにとらわれず可変長プレフィックスでアドレスを割り当てる

**四国めたん**：MTU。

*（1.5秒 考えてみよう）*

**ずんだもん**：Maximum Transmission Unit。

**ずんだもん**：1回で送れるデータの最大サイズ

**四国めたん**：QoS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Quality of Service。

**ずんだもん**：通信の優先度・帯域を制御して品質を保証する

**四国めたん**：CSMA/CD。

*（1.5秒 考えてみよう）*

**ずんだもん**：Carrier Sense Multiple Access with Collision Detection。

**ずんだもん**：有線LANの衝突検出方式

**四国めたん**：CSMA/CA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Carrier Sense Multiple Access with Collision Avoidance。

**ずんだもん**：無線LANの衝突回避方式

**四国めたん**：SDN。

*（1.5秒 考えてみよう）*

**ずんだもん**：Software-Defined Networking。

**ずんだもん**：ソフトウェアでネットワークを集中制御する技術

**四国めたん**：PoE。

*（1.5秒 考えてみよう）*

**ずんだもん**：Power over Ethernet。

**ずんだもん**：LANケーブルで電力を供給する

**四国めたん**：LPWA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Low Power Wide Area。

**ずんだもん**：低消費電力・広域のIoT向け無線通信

**四国めたん**：CDN。

*（1.5秒 考えてみよう）*

**ずんだもん**：Content Delivery Network。

**ずんだもん**：コンテンツを分散配置して高速に配信する

**四国めたん**：URL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Uniform Resource Locator。

**ずんだもん**：Web上の資源の場所を示す記述

**四国めたん**：ネットワーク編は、ここまでよ。聞き取れなかった用語は、略語カードで復習してね。
