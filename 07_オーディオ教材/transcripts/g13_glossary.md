# 用語聞き流し13 企業活動・会計

> 企業活動・会計の頻出略語21語を、略語 → 間 → 正式名称と意味の順に読み上げます。

- 音声: [../audio/g13_glossary.mp3](../audio/g13_glossary.mp3)（約3分26秒）
- 音声合成: VOICEVOX:四国めたん、VOICEVOX:ずんだもん

**ずんだもん**：用語の聞き流し、企業活動・会計編なのだ。

**四国めたん**：略語を読み上げたら、少し間をあけるわね。意味を思い浮かべてから答えを聞いてね。

**四国めたん**：ROE。

*（1.5秒 考えてみよう）*

**ずんだもん**：Return On Equity。

**ずんだもん**：自己資本利益率（当期純利益 / 自己資本）

**四国めたん**：ROA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Return On Assets。

**ずんだもん**：総資産利益率（利益 / 総資産）

**四国めたん**：NPV。

*（1.5秒 考えてみよう）*

**ずんだもん**：Net Present Value。

**ずんだもん**：正味現在価値。将来のキャッシュフローの現在価値 − 投資額

**四国めたん**：IRR。

*（1.5秒 考えてみよう）*

**ずんだもん**：Internal Rate of Return。

**ずんだもん**：内部収益率。NPVが0になる割引率

**四国めたん**：EOQ。

*（1.5秒 考えてみよう）*

**ずんだもん**：Economic Order Quantity。

**ずんだもん**：経済的発注量。発注費と保管費の合計が最小になる発注量

**四国めたん**：JIT。

*（1.5秒 考えてみよう）*

**ずんだもん**：Just In Time。

**ずんだもん**：必要なものを必要なときに必要な量だけ生産する方式

**四国めたん**：MRP。

*（1.5秒 考えてみよう）*

**ずんだもん**：Material Requirements Planning。

**ずんだもん**：資材所要量計画

**四国めたん**：TQC / TQM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Total Quality Control / Management。

**ずんだもん**：全社的品質管理／総合的品質マネジメント

**四国めたん**：QC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Quality Control。

**ずんだもん**：品質管理（QC七つ道具：パレート図、特性要因図など）

**四国めたん**：PDCA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Plan, Do, Check, Act。

**ずんだもん**：計画・実行・評価・改善の管理サイクル

**四国めたん**：OODA。

*（1.5秒 考えてみよう）*

**ずんだもん**：Observe, Orient, Decide, Act。

**ずんだもん**：観察・状況判断・意思決定・行動の意思決定サイクル

**四国めたん**：IE。

*（1.5秒 考えてみよう）*

**ずんだもん**：Industrial Engineering。

**ずんだもん**：作業や工程を分析・改善する生産工学

**四国めたん**：OR。

*（1.5秒 考えてみよう）*

**ずんだもん**：Operations Research。

**ずんだもん**：数理的手法で最適な意思決定を支援する

**四国めたん**：PL / P/L。

*（1.5秒 考えてみよう）*

**ずんだもん**：Profit and Loss statement。

**ずんだもん**：損益計算書

**四国めたん**：BS / B/S。

*（1.5秒 考えてみよう）*

**ずんだもん**：Balance Sheet。

**ずんだもん**：貸借対照表

**四国めたん**：CF / C/F。

*（1.5秒 考えてみよう）*

**ずんだもん**：Cash Flow statement。

**ずんだもん**：キャッシュフロー計算書

**四国めたん**：CEO。

*（1.5秒 考えてみよう）*

**ずんだもん**：Chief Executive Officer。

**ずんだもん**：最高経営責任者

**四国めたん**：CIO。

*（1.5秒 考えてみよう）*

**ずんだもん**：Chief Information Officer。

**ずんだもん**：最高情報責任者。IT戦略の責任者

**四国めたん**：CISO。

*（1.5秒 考えてみよう）*

**ずんだもん**：Chief Information Security Officer。

**ずんだもん**：最高情報セキュリティ責任者

**四国めたん**：CFO。

*（1.5秒 考えてみよう）*

**ずんだもん**：Chief Financial Officer。

**ずんだもん**：最高財務責任者

**四国めたん**：HRM。

*（1.5秒 考えてみよう）*

**ずんだもん**：Human Resource Management。

**ずんだもん**：人的資源管理

**四国めたん**：企業活動・会計編は、ここまでよ。聞き取れなかった用語は、略語カードで復習してね。
