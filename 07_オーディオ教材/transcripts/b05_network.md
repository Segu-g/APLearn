# 科目B攻略5 ネットワーク

**春日部つむぎ**：マジ？どういう人が選ぶと得なの？

**冥鳴ひまり**：ポート番号やDNS、NATなどの基本用語を覚えている人ですね。空欄補充が知識で即答できるので、時間が読みやすいんです。

**冥鳴ひまり**：問1の情報セキュリティと共通する知識も多いので、セキュリティと一緒に勉強すると効率がいいですよ。

**春日部つむぎ**：逆に、避けた方がいい人は？

**冥鳴ひまり**：ルータとスイッチの違いや、プライベートアドレスとグローバルアドレスの区別があやふやな人ですね。

**冥鳴ひまり**：構成図の上でパケットを追う問題が中心なので、機器の役割が分からないと手が止まってしまいます。

**春日部つむぎ**：じゃあ、最近はどんなテーマが出てるの？

**冥鳴ひまり**：令和4年度春期から令和7年度秋期までの8回を見ると、一番多いのは構成変更の事例です。

**冥鳴ひまり**：令和7年度秋期の問5は、社内サーバをクラウドへ移す話でした。NATや経路表、ファイアウォールのルールを書き換えます。

**冥鳴ひまり**：令和5年度秋期の問5はメールサーバの構築で、DNSのMXレコードや、OP25Bという迷惑メール対策が問われました。

**冥鳴ひまり**：令和7年度春期の問5は障害対応です。IPアドレスの重複を、ARPテーブルとMACアドレスの食い違いから見つけました。

**春日部つむぎ**：クラウド移行、メール、障害対応……。どれも会社のネットワークをいじる話なんだね。

**冥鳴ひまり**：そうなんです。そして、多くの回でファイアウォールの許可ルールの空欄が出ます。ここは確実に取りたいですね。

**春日部つむぎ**：解くときは、どういう順番で読めばいいの？

**冥鳴ひまり**：1問は25分くらいが目安です。最初の2、3分で設問を先に読んで、何を探すか決めておきます。

**冥鳴ひまり**：次に構成図とアドレスの一覧を照らし合わせて、どの機器がどのセグメントにあるかを確認します。

**冥鳴ひまり**：そして通信を問われたら、パケットが通る機器を順番に指でたどります。各区間で宛先と送信元が何になるかを意識してください。

**春日部つむぎ**：CBTだと問題に書き込めないよね？

**冥鳴ひまり**：はい。メモ用紙に、通り道を「PC、L3SW、FW、プロキシ」のように矢印で書き出しておくと迷いませんよ。

**冥鳴ひまり**：空欄や計算を先に片付けて、記述は後に回しましょう。時間配分を誤ると、点数が冥界送りになりますからね。

**春日部つむぎ**：ひまっち、さらっと怖いこと言うじゃん。ウケる。

**冥鳴ひまり**：では、ケーススタディです。出典は令和4年度春期 応用情報技術者試験 午後 問5、「ネットワークの構成変更」です。

**冥鳴ひまり**：P社は、本社と営業所をIPsecルータによるインターネットVPNでつないでいます。

**冥鳴ひまり**：社内のPCがインターネットや外部のSaaSを使うときは、DMZにあるプロキシサーバを経由する決まりです。

**冥鳴ひまり**：ところがSaaSの利用が増えて、ファイアウォールのセッション情報が増え、応答が遅くなってしまいました。

**冥鳴ひまり**：そこで、SaaS宛ての通信だけはプロキシを通さず、各拠点のIPsecルータから直接インターネットへ出すように変えます。

**春日部つむぎ**：混んでる道を避けて、抜け道を作るってことだね。

**冥鳴ひまり**：最初の設問です。営業所のPCがSaaSを使うとき、本社のファイアウォールからプロキシへ向かうパケットの宛先と送信元を答えます。

**春日部つむぎ**：SaaSを使うんだから、宛先はSaaSでしょ？送信元は、本社に届いてるからIPsecルータ？

**冥鳴ひまり**：それが、まさに出題者のねらいなんです。解答例は、宛先がプロキシサーバ、送信元が営業所のPCです。

**春日部つむぎ**：えっ、両方ハズレじゃん！なんで？

**冥鳴ひまり**：まず宛先です。PCのブラウザにはプロキシサーバが設定されているので、PCが送る通信はプロキシ宛てになります。

**冥鳴ひまり**：SaaSへ接続し直すのは、プロキシサーバの仕事なんです。

**冥鳴ひまり**：次に送信元です。IPsecのトンネルは、元のパケットを包んで運ぶだけなので、中身の送信元は書き換わりません。

**冥鳴ひまり**：本社のIPsecルータで包みを外したパケットは、送信元が営業所のPCのまま進みます。

**冥鳴ひまり**：採点講評でも、IPsecルータと答える誤りが多かったと書かれています。

**春日部つむぎ**：トンネルは封筒に入れて運ぶだけで、中の手紙の差出人は変わらない、ってことか。

**冥鳴ひまり**：可愛い言い換えですね、そのとおりです。

**冥鳴ひまり**：もう一問、経路表の記述です。本社のL3SWに追加する経路を、q-SaaSという言葉を使って40字以内で答えます。

**冥鳴ひまり**：解答例は「q-SaaS宛ての通信のネクストホップがIPsecルータ1となる経路」です。

**春日部つむぎ**：経路って、宛先と次に渡す相手のセットで書けばいいんだ。

**冥鳴ひまり**：はい。経路表の要素、つまり宛先とネクストホップで書くのがコツですよ。

**春日部つむぎ**：ほかに、よく出る書き方とか、ひっかけってある？

**冥鳴ひまり**：ネットワークアドレスを答える問題は要注意です。ホスト部をゼロにして書きます。

**冥鳴ひまり**：令和5年度秋期では、PC側のインタフェースが 192.168.0.1/24 なので、答えは 192.168.0.0 でした。

**冥鳴ひまり**：講評では、端末のIPアドレスをそのまま書いた誤答が多かったそうです。

**冥鳴ひまり**：もう一つ、OP25Bとオープンリレー防止の混同です。OP25Bは、ISPの利用者が外部へ直接メールを送るのを止める仕組みです。

**冥鳴ひまり**：オープンリレー防止は、社外から社外へのメールを中継しないことです。令和7年度秋期で、ここを取り違えた誤答が目立ちました。

**春日部つむぎ**：ポート番号も覚えなきゃだよね。

**冥鳴ひまり**：はい。DNSは53番、SMTPは25番、HTTPは80番、HTTPSは443番、SSHは22番。この5つは即答できるようにしましょう。

**冥鳴ひまり**：それから、ホスト数は2のn乗ひく2です。ネットワークアドレスとブロードキャストアドレスの分を引き忘れないでくださいね。

**冥鳴ひまり**：では、ミニクイズです。第1問。DNSで、プライマリサーバのゾーン情報をセカンダリサーバに複製する仕組みを何と言うでしょう。

*（4秒 考えてみよう）*

**春日部つむぎ**：えっと、コピーだから……ゾーン転送？

**冥鳴ひまり**：正解です。令和5年度春期の問5で空欄として出て、正答率が低かったところです。DNSの管理範囲がゾーン、その複製がゾーン転送ですね。

**冥鳴ひまり**：第2問。1人が10分間に120Mバイト通信します。これは何Mビット毎秒でしょう。

*（4秒 考えてみよう）*

**春日部つむぎ**：バイトを8倍して、960Mビット。10分は600秒だから……割って1.6Mビット毎秒！

**冥鳴ひまり**：正解です。令和4年度秋期の問5で出た計算です。バイトからビットへは8倍、分から秒へは60倍。この換算を落ち着いてやれば取れますよ。

**冥鳴ひまり**：最後にまとめです。一つ目、構成図の上でパケットを指でたどり、各区間の宛先と送信元を確認すること。

**冥鳴ひまり**：二つ目、プロキシを使うと宛先はプロキシ、IPsecトンネルでは送信元が変わらないこと。

**冥鳴ひまり**：三つ目、ポート番号やDNSの用語、ネットワークアドレスの計算は知識で即答して、確実に点にすること。

**春日部つむぎ**：パケットの通り道を追えば、ネットワークはこわくないってことだね！

**冥鳴ひまり**：はい。次回はデータベースです。またお会いしましょうね。
