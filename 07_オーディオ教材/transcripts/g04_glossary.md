# 用語聞き流し4 データベース

> データベースの頻出略語18語を、略語 → 間 → 正式名称と意味の順に読み上げます。

- 音声: [../audio/g04_glossary.mp3](../audio/g04_glossary.mp3)（約3分23秒）
- 音声合成: VOICEVOX:四国めたん、VOICEVOX:ずんだもん

**ずんだもん**：用語の聞き流し、データベース編なのだ。

**四国めたん**：略語を読み上げたら、少し間をあけるわね。意味を思い浮かべてから答えを聞いてね。

**四国めたん**：DBMS。

*（1.5秒 考えてみよう）*

**ずんだもん**：DataBase Management System。

**ずんだもん**：データベース管理システム

**四国めたん**：RDBMS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Relational DBMS。

**ずんだもん**：表形式（関係モデル）のDBMS

**四国めたん**：SQL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Structured Query Language。

**ずんだもん**：関係データベースを操作する言語

**四国めたん**：DDL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Data Definition Language。

**ずんだもん**：データ定義言語（CREATE、DROP など）

**四国めたん**：DML。

*（1.5秒 考えてみよう）*

**ずんだもん**：Data Manipulation Language。

**ずんだもん**：データ操作言語（SELECT、INSERT、UPDATE、DELETE）

**四国めたん**：DCL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Data Control Language。

**ずんだもん**：データ制御言語（GRANT、REVOKE など）

**四国めたん**：E-R図。

*（1.5秒 考えてみよう）*

**ずんだもん**：Entity-Relationship Diagram。

**ずんだもん**：実体と関連でデータ構造を表す図

**四国めたん**：ACID。

*（1.5秒 考えてみよう）*

**ずんだもん**：Atomicity, Consistency, Isolation, Durability。

**ずんだもん**：トランザクションが満たすべき4つの性質

**四国めたん**：2PC。

*（1.5秒 考えてみよう）*

**ずんだもん**：Two-Phase Commit。

**ずんだもん**：2相コミット。分散DBで全サイトの更新をそろえる手順

**四国めたん**：NoSQL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Not only SQL。

**ずんだもん**：関係モデル以外のDB（キーバリュー型、ドキュメント型など）

**四国めたん**：KVS。

*（1.5秒 考えてみよう）*

**ずんだもん**：Key-Value Store。

**ずんだもん**：キーと値の組でデータを管理するNoSQL

**四国めたん**：BASE。

*（1.5秒 考えてみよう）*

**ずんだもん**：Basically Available, Soft state, Eventually consistent。

**ずんだもん**：結果整合性を重視するNoSQLの特性

**四国めたん**：DWH。

*（1.5秒 考えてみよう）*

**ずんだもん**：Data WareHouse。

**ずんだもん**：意思決定のために時系列データを統合・蓄積するDB

**四国めたん**：OLAP。

*（1.5秒 考えてみよう）*

**ずんだもん**：OnLine Analytical Processing。

**ずんだもん**：DWHのデータを多次元で分析する処理

**四国めたん**：ETL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Extract, Transform, Load。

**ずんだもん**：データを抽出・変換・格納してDWHに取り込む処理

**四国めたん**：BI。

*（1.5秒 考えてみよう）*

**ずんだもん**：Business Intelligence。

**ずんだもん**：蓄積データを分析し経営判断に活かす手法・ツール

**四国めたん**：CRUD。

*（1.5秒 考えてみよう）*

**ずんだもん**：Create, Read, Update, Delete。

**ずんだもん**：データの基本操作。CRUD図で機能とデータの関係を表す

**四国めたん**：WAL。

*（1.5秒 考えてみよう）*

**ずんだもん**：Write-Ahead Logging。

**ずんだもん**：更新前にログを先に書き込む方式（障害回復の前提）

**四国めたん**：データベース編は、ここまでよ。聞き取れなかった用語は、略語カードで復習してね。
