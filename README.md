# APLearn — 応用情報技術者試験 学習資料

応用情報技術者試験（AP）合格のための自習用資料集です。Web上の公開情報（IPAシラバス・試験要綱・公開過去問の傾向など）をもとに、分野ごとに分かりやすくまとめています。

- 形式：Markdown（GitHub や VS Code のプレビューで閲覧。図は Mermaid）
- 対応：**2026年度〜のCBT方式**（科目A＝旧午前、科目B＝旧午後）、シラバス Ver.7.2

## まずはここから

1. [試験概要](00_はじめに/01_試験概要.md) — 試験の構成、CBT化の変更点、日程
2. [学習計画と勉強法](00_はじめに/02_学習計画と勉強法.md) — 3か月プランとこの資料の使い方
3. **[インタラクティブ教材](06_インタラクティブ教材/index.html)** — `06_インタラクティブ教材/index.html` をブラウザで開く（クイズ・単語カード・計算シミュレータ・聞き流し講座）

## 3種類の教材

| 種類 | 場所 | 使いどころ |
|---|---|---|
| 📖 解説資料（Markdown） | `00`〜`05` | じっくり読んで理解する。確認問題つき |
| 🖱️ インタラクティブ教材（HTML） | [`06_インタラクティブ教材/`](06_インタラクティブ教材/index.html) | 手を動かして覚える。四択クイズ（本番モードあり）、略語カード、計算シミュレータ12種 |
| 🎧 オーディオ教材（MP3） | [`07_オーディオ教材/`](07_オーディオ教材/README.md) | 通勤中に聞き流す。ずんだもん・四国めたんの掛け合い解説 全16回（約80分） |

💡 HTML教材は外部ライブラリを使わないので、ネット接続なしでもブラウザで開くだけで動きます（`file://` で動作）。

## 各資料の読み方

- 各章冒頭の **★の数** が重要度です（★★★ = 毎回のように出る）。
- 💡 は覚え方のコツ、⚠️ はひっかけ注意です。
- 章末の **確認問題** はオリジナル問題です。`解答・解説` をクリックすると答えが開きます。
