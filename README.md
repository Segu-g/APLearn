# APLearn — 応用情報技術者試験 学習資料

応用情報技術者試験（AP）合格のための自習用資料集です。IPA のシラバス Ver.7.2 の全中分類をカバーする解説資料、**IPA 公表の過去問 科目A 13回分（1,040問）の全問解説と科目B 8回分（88問）の解き方ガイド**、クイズ・シミュレータ、音声講座をそろえ、このリポジトリだけで合格を目指せる構成にしています。

- 形式：Markdown（GitHub や VS Code のプレビューで閲覧。図は Mermaid）
- 対応：**2026年度〜のCBT方式**（科目A＝旧午前、科目B＝旧午後）、シラバス Ver.7.2

## まずはここから

1. [試験概要](00_はじめに/01_試験概要.md) — 試験の構成、CBT化の変更点、日程
2. [学習計画と勉強法](00_はじめに/02_学習計画と勉強法.md) — 3か月プランとこの資料の使い方
3. **[インタラクティブ教材](06_インタラクティブ教材/index.html)** — `06_インタラクティブ教材/index.html` をブラウザで開く（クイズ・単語カード・計算シミュレータ・聞き流し講座）
4. **[過去問解説](08_過去問解説/README.md)** — 科目A 1,040問の解説、科目B 分野別ガイド、中分類別の出題数と頻出キーワード
5. **[用語集](09_用語集/README.md)** — シラバス全23分野・約4,900語を1行説明＋試験のポイントで。★★★ から覚えて [用語ドリル](06_インタラクティブ教材/terms.html) で確認

## 3種類の教材

| 種類 | 場所 | 使いどころ |
|---|---|---|
| 📖 解説資料（Markdown） | `00`〜`05` | じっくり読んで理解する。確認問題・シラバス用語チェックリストつき |
| 📚 用語集（Markdown） | [`09_用語集/`](09_用語集/README.md) | 用語を素早く覚える。全23分野・約4,900語を重要度★つきで。過去問で問われた語は問題へのリンクつき |
| 📝 過去問解説（Markdown） | [`08_過去問解説/`](08_過去問解説/README.md) | IPA 公表の過去問で実戦練習。科目A 13回分・1,040問の全問解説、科目B 8回分の解き方ガイド |
| 🖱️ インタラクティブ教材（HTML） | [`06_インタラクティブ教材/`](06_インタラクティブ教材/index.html) | 手を動かして覚える。四択クイズ（オリジナル249問＋IPA過去問1,040問、本番モードあり）、用語ドリル（約4,900語）、略語カード、計算シミュレータ12種 |
| 🎧 オーディオ教材（MP3） | [`07_オーディオ教材/`](07_オーディオ教材/README.md) | 通勤中に聞き流す。ずんだもん・四国めたんの掛け合い解説 全40回（約3時間半）、冥鳴ひまり・春日部つむぎの科目B攻略編 全11回（約1時間40分）、用語聞き流し14本（約50分） |

💡 HTML教材は外部ライブラリを使わないので、ネット接続なしでもブラウザで開くだけで動きます（`file://` で動作）。

## 各資料の読み方

- 各章冒頭の **★の数** が重要度です（★★★ = 毎回のように出る）。
- 💡 は覚え方のコツ、⚠️ はひっかけ注意です。
- 章末の **確認問題** はオリジナル問題です。`解答・解説` をクリックすると答えが開きます。
