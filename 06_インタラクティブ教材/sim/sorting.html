整列アルゴリズム可視化

バブル・選択・挿入・クイック・マージ・ヒープソートの動きを棒グラフで再生します。1手ずつのステップ実行や速度調整ができ、比較回数と交換回数を数えます。

例題を読み込む：
比較 0 回 交換 0 回 書込み（マージ） 0 回

比較中交換・書込みピボット位置が確定

同じデータで比較

「交換」は2つの要素の入替え、「書込み」はマージソートで作業領域から配列に値を書き戻した回数です。

計算量と安定性

方式考え方平均最悪安定
バブルソート（基本交換法）隣同士を比較して交換O(n²)O(n²)○
選択ソート（基本選択法）未整列部分の最小値を選んで先頭と交換O(n²)O(n²)×
挿入ソート（基本挿入法）整列済み部分の適切な位置に挿入。ほぼ整列済みなら O(n) に近いO(n²)O(n²)○
クイックソートピボットより小さい群・大きい群に分割を繰り返すO(n log n)O(n²)×
マージソート半分に分割して整列し、併合（マージ）する。作業領域が必要O(n log n)O(n log n)○
ヒープソートヒープを作り、根（最大値）を取り出すことを繰り返すO(n log n)O(n log n)×

安定なソート：同じキーの要素の元の並び順が保たれるソート。このページのクイックソートは先頭の要素をピボットにしているので、整列済みのデータでは分割が偏って O(n²) になります。
