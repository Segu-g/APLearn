<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **クラッシング** | **ファストトラッキング** | クラッシングは要員追加など資源を投入して短縮する（コスト増）。ファストトラッキングは順番の作業を並行・前倒しして短縮する（手戻りリスク増）。 |
| **プロジェクトバッファ** | **合流バッファ** | プロジェクトバッファはクリティカルチェーンの最後に置き完了日を守る。合流バッファは非クリティカルな経路がクリティカルチェーンに合流する直前に置く。 |
| **コンティンジェンシー予備** | **マネジメント予備** | コンティンジェンシー予備は特定済みのリスクに備えコストベースラインに含む。マネジメント予備は想定外の事象に備えベースラインに含まず、使うには承認が要る。 |
| **資源平準化** | **資源円滑化** | 平準化は余裕を超えて作業をずらすことがあり、クリティカルパスが延びうる。円滑化は余裕（フロート）の範囲内でずらすので完了日は変わらない。 |
| **リード** | **ラグ** | リードは後続作業を前倒しで開始できる時間（計算では引く）。ラグは後続作業の開始を遅らせる待ち時間（計算では足す）。 |
| **アローダイアグラム** | **PDM（プレシデンスダイアグラム法）** | アローダイアグラムは矢印が作業でFS関係のみ、依存関係にダミー作業を使う。PDMは四角が作業で、FS・SS・FF・SFとリード・ラグを表せる。 |
| **PERT** | **CPM（クリティカルパス法）** | PERTは三点見積りで所要時間の不確実性を確率的に扱う。CPMは確定した所要時間とコストのトレードオフ（費用勾配による短縮）を扱う。 |
| **類推見積り** | **ボトムアップ見積り** | 類推見積りは過去の類似案件から全体を見積もり、早期に使えるが精度は低い。ボトムアップ見積りはワークパッケージごとに積み上げ、精度は高いが手間がかかる。 |
| **ファンクションポイント法** | **LOC法** | ファンクションポイント法は機能の数と複雑さで規模を測り、言語に依存しない。LOC法はソースコードの行数で測り、言語や書き方に依存する。 |
| **SV（スケジュール差異）／SPI（スケジュール効率指数）** | **CV（コスト差異）／CPI（コスト効率指数）** | どちらもEVが主役。スケジュールはEVとPVを比べ（EV−PV、EV÷PV）、コストはEVとACを比べる（EV−AC、EV÷AC）。 |
| **回避（脅威への戦略）** | **軽減（脅威への戦略）** | 回避は計画を変えてリスクの原因そのものを取り除く。軽減は発生確率や影響度を下げるだけで、リスクは残る。 |
| **活用（好機への戦略）** | **強化（好機への戦略）** | 活用は好機の発生確率を100%にして確実に実現させる。強化は発生確率や影響度を高めるが、確実にするわけではない。 |
| **プッシュ型コミュニケーション** | **プル型コミュニケーション** | プッシュ型は送り手が特定の相手にメールや報告書を送る。プル型は情報をポータル等に置き、受け手が必要なときに取りに行く。 |
| **品質保証の遂行** | **品質管理の遂行** | 品質保証の遂行はプロセスが適切に実施されているかを確認する（実行のプロセス群）。品質管理の遂行は成果物を検査・測定する（管理のプロセス群）。 |
| **是正処置** | **予防処置** | 是正処置は起きたずれや不適合を直して計画どおりに戻す。予防処置はまだ起きていない問題の原因を取り除き、未然に防ぐ。 |
