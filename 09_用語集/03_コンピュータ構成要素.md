<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **ライトスルー** | **ライトバック** | ライトスルーは毎回キャッシュと主記憶の両方に書く（一致が保たれるが遅い）。ライトバックはキャッシュだけに書き、追い出し時に主記憶へ書き戻す（速いが一時的に不一致）。 |
| **DRAM** | **SRAM** | DRAM はコンデンサで記憶しリフレッシュが必要、安価・大容量で主記憶用。SRAM はフリップフロップで記憶しリフレッシュ不要、高速・高価でキャッシュ用。 |
| **CISC** | **RISC** | CISC は複雑な命令が多く可変長でマイクロプログラム制御が中心。RISC は単純な固定長命令をワイヤードロジックで実行し、パイプラインに向く。 |
| **スーパースカラ** | **VLIW** | どちらも複数命令を同時に実行するが、スーパースカラは実行時にハードウェアが命令を振り分け、VLIW はコンパイル時に複数の動作を1つの長い命令にまとめる。 |
| **SIMD** | **MIMD** | SIMD は1つの命令で複数のデータを同時に処理（GPU・ベクトル処理）。MIMD は各プロセッサが別々の命令を別々のデータに実行（マルチプロセッサ）。 |
| **内部割込み** | **外部割込み** | 内部割込みは実行中のプログラムが原因（ゼロ除算・SVC・ページフォールト）。外部割込みはプログラムの外が原因（入出力完了・タイマー・電源異常）。 |
| **直接アドレス指定** | **間接アドレス指定** | 直接はアドレス部の値がそのまま実効アドレス。間接はアドレス部が指す番地の内容が実効アドレスで、主記憶を2回参照する。 |
| **即値アドレス指定** | **直接アドレス指定** | 即値はアドレス部の値そのものがデータで主記憶を参照しない。直接はアドレス部の値が番地で、その番地のデータを使う。 |
| **相対アドレス指定** | **ベースアドレス指定** | 相対はプログラムカウンター＋アドレス部、ベースはベースレジスタ＋アドレス部で実効アドレスを求める。基準にするレジスタが違う。 |
| **密結合マルチプロセッサシステム** | **疎結合マルチプロセッサシステム** | 密結合は主記憶を共有し1つの OS で制御（主記憶の競合が隘路）。疎結合はプロセッサごとに主記憶と OS を持ち通信で連携（通信オーバーヘッドが隘路）。 |
| **ダイレクトマッピング方式** | **フルアソシエイティブ方式** | ダイレクトマッピングは各ブロックの置き場所がキャッシュ内の1か所に決まる。フルアソシエイティブはどこにでも置ける。中間がセットアソシエイティブ。 |
| **メモリインタリーブ** | **キャッシュメモリ** | メモリインタリーブは主記憶を複数バンクに分けて並行アクセスする。キャッシュメモリは主記憶のデータの一部を高速なメモリにコピーしておく。 |
| **シークタイム** | **サーチタイム** | シークタイムはヘッドを目的のトラックへ移動させる時間。サーチタイムは目的のセクタが回ってくるまでの回転待ち時間（平均は半回転）。 |
| **CPI** | **MIPS** | CPI は1命令あたりの平均クロック数（小さいほど速い）。MIPS は1秒間に実行できる命令数を百万単位で表す（大きいほど速い）。MIPS＝クロック周波数（MHz）÷CPI。 |
| **DMA 方式** | **プログラム制御方式** | DMA 方式は DMA コントローラーが CPU を介さず主記憶と装置間で転送し、その間 CPU は別の処理ができる。プログラム制御方式は CPU が入出力命令で1つずつ転送する。 |
| **ビッグエンディアン** | **リトルエンディアン** | ビッグエンディアンは上位バイトから小さい番地へ、リトルエンディアンは下位バイトから小さい番地へ格納する。0x1234 なら 12 34 と 34 12。 |
| **ホットプラグ** | **プラグアンドプレイ** | ホットプラグは電源を入れたまま抜き差しできる機能。プラグアンドプレイは接続した装置を OS が自動認識して設定する機能。 |
| **液晶ディスプレイ** | **有機 EL ディスプレイ** | 液晶は自ら光らず、バックライトの光の透過を液晶で制御する。有機 EL は素子が自発光するのでバックライト不要で薄型・高コントラスト。 |
| **ZigBee** | **Bluetooth** | ZigBee は低速・低消費電力で多数のセンサをつなぐセンサネットワーク向け。Bluetooth はヘッドセットなどの周辺機器を接続する近距離無線。 |
