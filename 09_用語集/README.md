# 用語集 — 分野別に用語と説明をまとめた資料

シラバス Ver.7.2 の全23中分類について、用語を **1行の説明＋試験のポイント** でまとめました。全 **4872語**、そのうち重要度 ★★★ が 606語、★★ が 1280語です。科目A過去問（13回・1,040問）で実際に問われた 1104語には、その問題へのリンクを付けています。

## 効率よく覚える3ステップ

1. **★★★ から覚える**：まず [最重要用語まとめ](00_最重要用語まとめ.md)（全分野の★★★）か、各分野の冒頭の「★★★ 最重要用語」を読む。科目Aの用語問題の多くはここから出ます。
2. **テストで確かめる**：[用語ドリル](../06_インタラクティブ教材/terms.html) の4択テスト・カードで、説明 → 用語、用語 → 説明の両方向で答えられるか確認する。間違えた語は自動で「苦手」に入ります。
3. **★★ → ★ と広げる**：★★★ が8割言えるようになったら ★★ へ。まぎらわしい用語の表で違いを説明できるようにする。

💡 **★の付け方**：過去13回の科目Aで繰り返し問われた語や、科目Bの前提になる基本語が ★★★、1回問われた語・定番の知識が ★★、それ以外のシラバス用語が ★ です。★ の語も出題範囲ですが、時間が限られているなら後回しにして構いません。

## 作り方・修正のしかた

元データは `data/*.json` です。修正したら `python3 09_用語集/tools/build_terms.py` で Markdown と用語ドリルを作り直します。詳しくは [README_DEV.md](README_DEV.md)。
