## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **BCP（事業継続計画）** | **BCM（事業継続マネジメント）** | BCPは重要業務を継続・早期復旧するための「計画」。BCMはBCPの策定・訓練・見直しをPDCAで回す「管理活動全体」。 |
| **PM理論** | **SL理論** | PM理論は目標達成機能（P）と集団維持機能（M）の2軸で型を分ける。SL理論は部下の成熟度に応じて指示型→説得型→参加型→委任型と変える。 |
| **事業部制組織** | **職能別組織（機能別組織）** | 事業部制は製品・地域ごとに利益責任を持つ組織単位を作る。職能別は営業・製造など機能ごとに分け、利益責任はトップに集中する。 |
| **コーチング** | **メンタリング** | コーチングは問いかけで相手から答えを引き出す。メンタリングは経験豊富な先輩が継続的に助言・支援する。 |
| **損益分岐点** | **目標利益売上高** | 損益分岐点売上高＝固定費÷限界利益率（利益0）。目標利益売上高＝(固定費＋目標利益)÷限界利益率。 |
| **ROA（総資産利益率）** | **ROE（自己資本利益率）** | ROAは利益÷総資産で資産全体の効率、ROEは当期純利益÷自己資本で株主資本の効率。借入を増やすとROEだけが上がりやすい。 |
| **NPV法（正味現在価値法）** | **回収期間法（PBP法）** | NPV法は将来CFを現在価値に割り引き、投資額との差で評価する。回収期間法は何年で回収できるかで評価し、時間価値や回収後のCFを考慮しない。 |
| **発注点** | **EOQ（経済的発注量）** | 発注点は「いつ発注するか」の在庫水準（使用量×調達期間＋安全在庫）。EOQは「1回にどれだけ発注するか」の量。 |
| **マクシミン原理** | **マクシマックス原理** | マクシミンは各案の最小利得の中で最大を選ぶ（悲観的）。マクシマックスは各案の最大利得の中で最大を選ぶ（楽観的）。 |
| **生産者危険** | **消費者危険** | 生産者危険は良いロットが不合格になる確率（α、売り手が損）。消費者危険は悪いロットが合格になる確率（β、買い手が損）。 |
| **親和図法** | **連関図法** | 親和図法は似た意見をグループ化してまとめる。連関図法は複雑に絡み合った原因と結果の関係を矢印で結んで解明する。 |
| **連関図法** | **系統図法** | 連関図法は要因どうしの因果関係を網の目状に結ぶ。系統図法は目的→手段→さらに細かい手段とツリー状に展開する。 |
| **移動平均法（需要予測）** | **指数平滑法** | 移動平均法は直近数期間の実績の単純平均で予測する。指数平滑法は前回予測を実績との誤差×αで修正し、直近ほど重みが大きい。 |
| **PTS法** | **ワークサンプリング法** | PTS法は基本動作ごとの標準時間を組み合わせて作業時間を設定する。ワークサンプリング法はランダムな瞬間観測の比率から稼働率などを推定する。 |
| **ブレーンストーミング** | **親和図法** | ブレーンストーミングは批判厳禁でアイデアを広げる発散技法。親和図法は出たアイデアを似たものでまとめる収束技法。 |
