<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **TCP** | **UDP** | TCPはコネクション型で確認応答・再送・順序制御があり信頼性重視。UDPはコネクションレスで軽く速い（DNS問合せ・NTP・音声動画）。 |
| **CSMA/CD** | **CSMA/CA** | CDは送信中に衝突を「検出」して再送する有線LANの方式。CAは送信前に待って衝突を「回避」する無線LANの方式。 |
| **ブロードキャスト** | **マルチキャスト** | ブロードキャストは同一セグメントの全端末宛て。マルチキャストは特定グループの複数端末宛て（IPv4はクラスD）。どちらも一度の送信で届ける。 |
| **プロキシサーバ（フォワードプロキシ）** | **リバースプロキシサーバ** | フォワードプロキシはクライアント側で内部→外部の通信を代理する。リバースプロキシはWebサーバ側で外部→公開サーバの通信を中継する。 |
| **NAT** | **NAPT（IPマスカレード）** | NATはIPアドレスだけを1対1で変換。NAPTはポート番号も変換し、1つのグローバルアドレスを複数端末で共有できる。 |
| **ARP** | **RARP** | ARPはIPアドレスからMACアドレスを求める。RARPは逆にMACアドレスから自分のIPアドレスを求める。 |
| **回線交換** | **パケット交換** | 回線交換は通信中ずっと回線を占有し品質一定（加入電話）。パケット交換は回線を共有し効率が良いが遅延が変動する（インターネット）。 |
| **スイッチングハブ（L2スイッチ）** | **ルータ** | L2スイッチはMACアドレスで同一ネットワーク内を転送し、ブロードキャストも流す。ルータはIPアドレスでネットワーク間を中継し、ブロードキャストを越えさせない。 |
| **広域Ethernet** | **IP-VPN** | どちらも事業者の閉域網。広域EthernetはL2接続でルーティングプロトコルを自由に選べる。IP-VPNはL3（IP）接続。 |
| **POP3** | **IMAP4** | POP3はメールを端末にダウンロードして読む。IMAP4はサーバ上でメールを管理し、複数端末で状態を共有できる。 |
| **ハンドオーバー** | **ローミング** | ハンドオーバーは移動中に通信を切らずに基地局を切り替えること。ローミングは契約外のエリアで提携他社の設備を使うこと。 |
| **隠れ端末問題** | **さらし端末問題** | 隠れ端末は互いが見えずに同時送信してAPで衝突する問題（対策RTS/CTS）。さらし端末は他の通信が見えて送れるのに送信を控え効率が落ちる問題。 |
| **SDN** | **NFV** | SDNは制御機能と転送機能を分離してコントローラで集中制御する。NFVはルータやFWなどの機能を汎用サーバ上の仮想マシンで実現する。 |
| **MQTT** | **CoAP** | MQTTはTCP上のパブリッシュ／サブスクライブ型（ブローカー経由）。CoAPはUDP上でHTTP風のREST操作を行う。 |
| **ポーリング** | **セレクティング** | ポーリングは主局が従局に送るデータの有無を問い合わせる（従局→主局の送信）。セレクティングは主局が受信先を指定する（主局→従局の送信）。 |
