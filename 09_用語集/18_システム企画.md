<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **RFI** | **RFP** | RFIは要件が固まる前にベンダから技術・製品・実績の情報を集める。RFPは要件を示して具体的な提案書と見積書を依頼する。 |
| **RFP** | **RFQ** | RFPは提案（実現方法）と見積りを依頼する。RFQは仕様が決まったものの見積金額だけを依頼する。 |
| **請負契約** | **準委任契約** | 請負は仕事の完成に対価を払い、受注者に完成義務がある。準委任は作業の遂行に対価を払い、完成義務はない（善管注意義務のみ）。 |
| **定額契約** | **実費償還契約（CPIF，CPFF）** | 定額契約は金額を固定し、コスト超過リスクは受注者が負う。実費償還契約は実コストに報酬を加えて払い、コスト超過リスクは発注者が負う。 |
| **レベニューシェア** | **ランニングロイヤリティ** | レベニューシェアは開発したシステムの収益を発注者と受注者で分配する契約形態。ランニングロイヤリティは売上や数量に応じて払い続けるライセンスの使用料。 |
| **ファブレス** | **ファウンドリ** | ファブレスは工場を持たず設計・販売に集中し製造を委託する側。ファウンドリは他社から製造だけを受託する側。 |
| **OEM** | **ODM** | OEMは他社ブランド製品の製造を受託する。ODMは製品の設計から受託して製造する。 |
| **PBP** | **NPV（Net Present Value：正味現在価値）** | PBPは投資額を何年で回収できるかを見る（時間価値を考えない）。NPVは将来の効果を現在価値に割り引いて合計し投資額を引いた額で判断する。 |
| **NPV（Net Present Value：正味現在価値）** | **IRR** | NPVは割引率を決めて正味の現在価値（金額）を求め、正なら採用。IRRはNPVが0になる割引率（率）で、資本コストより大きければ採用。 |
| **機能要件** | **非機能要件** | 機能要件はシステムが何をするか（画面・処理など）。非機能要件は性能・可用性・使用性・セキュリティなど、どのくらいの品質で動くか。 |
| **SoR** | **SoE** | SoRは正確なデータの記録が目的の基幹系システム。SoEは顧客とのつながりを深めるためのシステムで、変化への俊敏さを重視する。 |
| **決定表（デシジョンテーブル）** | **デシジョンツリー** | 決定表は条件の組合せと動作を表形式で網羅する。デシジョンツリーは条件の分岐や意思決定の選択肢と結果を木構造で表す。 |
| **トレーサビリティ** | **アカウンタビリティ** | トレーサビリティは要求から設計・テストまでの対応関係を追跡できること。アカウンタビリティは決定理由や結果を説明する責任。 |
| **グリーン調達（グリーン購入）** | **CSR調達** | グリーン調達は環境負荷の小さい製品・サービスを優先して購入すること。CSR調達は環境に加え人権・労働・公正取引など取引先の社会的責任も評価する。 |
| **Fit to Standard** | **OOTB（Out Of The Box）** | Fit to Standardは業務をパッケージの標準機能に合わせて導入する進め方。OOTBは製品を追加開発なしでそのまま使える状態のこと。 |
