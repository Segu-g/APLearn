<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **可逆圧縮** | **非可逆圧縮** | 可逆圧縮は伸長すると完全に元に戻る（ZIP、PNG、GIF）。非可逆圧縮は情報の一部を捨てて高い圧縮率を得る（JPEG、MPEG、MP3）。 |
| **ラスターデータ（ビットマップデータ）** | **ベクターデータ** | ラスターは画素の集まりで拡大するとギザギザになる（写真向き）。ベクターは座標と数式で表し拡大しても劣化しない（図面・ロゴ向き）。 |
| **アウトラインフォント** | **ビットマップフォント** | アウトラインは輪郭を式で表し拡大しても滑らか。ビットマップはドットの集まりで表示は速いが拡大でギザギザになる。 |
| **JPEG** | **PNG** | JPEG は写真向きの非可逆圧縮。PNG はフルカラー・可逆圧縮でアルファチャネル（半透明）に対応。 |
| **GIF** | **PNG** | GIF は256色まででアニメーションに対応。PNG はフルカラーに対応し半透明も扱える。どちらも可逆圧縮。 |
| **H.264** | **H.265** | H.264（MPEG-4 AVC）はワンセグ・Blu-ray・配信で普及。H.265（HEVC）はその約2倍の圧縮効率で4K／8K 放送に使う。 |
| **コンテナフォーマット** | **コーデック** | コンテナは映像・音声などをまとめて格納する入れ物の形式（MP4 など）。コーデックは中身を圧縮・伸長する方式（H.264 など）。 |
| **標本化周波数** | **量子化ビット数** | 標本化周波数は1秒間に値を取り出す回数で、最高周波数の2倍以上必要。量子化ビット数は1回の値を何ビットで表すか。 |
| **加法混色** | **減法混色** | 加法混色は光の RGB を重ねるほど明るくなり3色で白（ディスプレイ）。減法混色は色材の CMY を重ねるほど暗くなり3色で黒（印刷）。 |
| **アンチエイリアシング** | **ディザリング** | アンチエイリアシングは輪郭のギザギザを中間色で滑らかに見せる。ディザリングは少ない色の点を混ぜて中間色を擬似的に表現する。 |
| **グローシェーディング** | **フォンシェーディング** | グローは頂点の明るさを補間し計算が軽い。フォンは法線を補間して画素ごとに計算し、ハイライトが自然だが重い。 |
| **AR** | **VR** | AR は現実の映像に仮想の情報を重ねる（拡張）。VR は完全な仮想世界に入り込ませる（置き換え）。 |
| **インターレース方式** | **プログレッシブ方式** | インターレースは奇数行と偶数行を交互に表示する。プログレッシブは全行を順に一度に表示する。 |
| **リニア編集** | **ノンリニア編集** | リニア編集はテープを先頭から順に再生・録画して編集する。ノンリニア編集はデジタル化した映像の任意の場面に直接アクセスして編集する。 |
| **ラジオシティ法** | **テクスチャマッピング** | ラジオシティ法は拡散反射面どうしの相互反射を計算して明るさを決める。テクスチャマッピングは物体表面に模様の画像を貼り付ける。 |

<a id="一問一答"></a>

## 一問一答（★★★）

説明を読んで用語を答えてください。クリックすると答えが開きます。

<details><summary>Q1. アナログ信号を標本化・量子化・符号化の3段階でデジタル化する方式（パルス符号変調）</summary>

**PCM**（Pulse Code Modulation）
</details>

<details><summary>Q2. アナログ信号を1秒間に標本化する回数（Hz）。サンプリング周波数ともいう</summary>

**標本化周波数**（sampling frequency）
</details>

<details><summary>Q3. 標本化した1回分の値を何ビットで表すか。多いほど振幅を細かく表現できる</summary>

**量子化ビット数**（quantization bits）
</details>

<details><summary>Q4. フルカラーの写真向け静止画形式。DCT を使った非可逆圧縮で、圧縮率を選べる</summary>

**JPEG**（Joint Photographic Experts Group）
</details>

<details><summary>Q5. 256色までの静止画形式。可逆圧縮（LZW）で、アニメーションや透過色に対応する</summary>

**GIF**（Graphics Interchange Format）
</details>

<details><summary>Q6. フルカラーに対応した可逆圧縮の静止画形式。アルファチャネル（半透明）を扱える</summary>

**PNG**（Portable Network Graphics）
</details>

<details><summary>Q7. 画像を画素（ピクセル）の集まりで表すデータ。拡大するとギザギザ（ジャギー）が目立つ</summary>

**ラスターデータ（ビットマップデータ）**（raster data）
</details>

<details><summary>Q8. 点の座標・線・曲線などを数式で表す画像データ。拡大・縮小しても劣化しない</summary>

**ベクターデータ**（vector data）
</details>

<details><summary>Q9. MPEG-4 AVC とも呼ばれる動画圧縮符号化方式。ワンセグ、Blu-ray、インターネット配信で広く使われる</summary>

**H.264**（MPEG-4 AVC）
</details>

<details><summary>Q10. 伸長すると完全に元のデータに戻る圧縮</summary>

**可逆圧縮**（lossless compression）
</details>

<details><summary>Q11. 人が気づきにくい情報を捨てることで、高い圧縮率を得る圧縮。完全には元に戻らない</summary>

**非可逆圧縮**（lossy compression）
</details>

<details><summary>Q12. 物体の形・光源・視点などの3次元データから、陰影や反射を計算して表示用の2次元画像を生成する処理</summary>

**レンダリング**（rendering）
</details>
