<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **組合せ論理回路** | **順序論理回路** | 組合せ論理回路は現在の入力だけで出力が決まり記憶をもたない。順序論理回路はフリップフロップで過去の状態を記憶し、出力に影響する。 |
| **NAND 回路** | **NOR 回路** | NAND は入力がすべて1のときだけ0、NOR は入力がすべて0のときだけ1。どちらも単独で全論理を作れる万能ゲート。 |
| **XOR 回路** | **XNOR 回路** | XOR は2入力が異なるとき1、XNOR は一致するとき1。XNOR は XOR の否定。 |
| **シーケンス制御** | **フィードバック制御** | シーケンス制御は決めた順序・条件で段階を進める。フィードバック制御は測定値と目標値の偏差をなくすように操作量を調整し続ける。 |
| **オープンループ制御** | **クローズドループ制御** | オープンループは結果を測らず決めた量だけ操作する。クローズドループは結果をセンサで測って操作に戻し、修正する。 |
| **センサー** | **アクチュエーター** | センサーは物理量を電気信号に変える入力側の部品。アクチュエーターは電気信号を動きに変える出力側の部品。 |
| **ASIC** | **FPGA** | ASIC は特定用途向けに製造時に回路を作り込み、後から変えられない。FPGA は製造後・実装後でも利用者が回路を書き換えられる。 |
| **マイクロプロセッサ** | **マイクロコントローラー** | マイクロプロセッサは CPU だけを1チップにしたもの。マイクロコントローラーは CPU に加えメモリ・タイマー・入出力も1チップに内蔵する。 |
| **インバータ** | **電源回路** | インバータは直流を交流に変換する。電源回路の AC/DC コンバータは交流を直流に、DC/DC コンバータは直流の電圧を変換する。 |
| **コンデンサ** | **コイル** | コンデンサは電荷をためて直流を通さず交流を通しやすい。コイルは磁界にエネルギーをためて直流を通し、急な電流変化（高周波）を妨げる。 |
| **A/D コンバータ** | **D/A コンバータ** | A/D はアナログ信号を標本化・量子化・符号化してデジタル値にする。D/A はデジタル値をアナログ電圧に戻す。 |
| **クロックゲーティング** | **パワーゲーティング** | クロックゲーティングはクロックを止めて動的電力を減らす。パワーゲーティングは電源を遮断し、リーク電流による静的電力も減らす。 |
| **同期式設計** | **非同期式設計** | 同期式は全フリップフロップを共通クロックで動かし解析が容易。非同期式は共通クロックを使わずハンドシェイクでタイミングを取る。 |
| **正論理** | **負論理** | 正論理は H を1、負論理は L を1とみなす。正論理の AND 回路は負論理では OR 回路として働く。 |
| **ダイオード** | **MOS トランジスタ** | ダイオードは電流を一方向にだけ流す（整流）。MOS トランジスタはゲート電圧で電流を ON/OFF・増幅する。 |
