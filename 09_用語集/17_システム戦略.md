<a id="まぎらわしい用語"></a>

## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **BPR** | **BPM** | BPRは業務プロセスを根本から一度に作り直す抜本改革。BPMは業務プロセスをPDCAで継続的に改善し続ける管理手法。 |
| **BPR** | **BPO** | BPRは業務の抜本的な再設計。BPOは自社のノンコア業務を業務プロセスごと外部の専門企業に委託すること。 |
| **ERP** | **SCM** | ERPは社内の基幹業務と経営資源を統合管理する。SCMは調達から販売までの供給連鎖を複数の企業にまたがって最適化する。 |
| **CRM** | **SFA** | CRMは顧客との関係全体を管理し顧客ロイヤルティを高める。SFAは営業活動（商談・訪問）の効率化に絞った仕組み。 |
| **KGI** | **KPI** | KGIは最終目標の達成度を測る指標（例：利益率）。KPIはその達成に向けた途中のプロセスの進み具合を測る指標（例：訪問件数）。 |
| **プログラムマネジメント** | **PMO** | プログラムマネジメントは複数プロジェクトを連携・統合して全体の価値を高める活動。PMOはそれらを横断的に管理・支援する組織。 |
| **SaaS** | **PaaS** | SaaSはアプリケーションまで事業者が提供する。PaaSはOS・ミドルウェア・実行環境までを提供し、アプリは利用者が載せる。 |
| **PaaS** | **IaaS** | PaaSはOS・ミドルウェアまで事業者が管理する。IaaSは仮想サーバなどの基盤だけで、OSから上は利用者が管理する。 |
| **ホスティングサービス** | **ハウジングサービス** | ホスティングは事業者のサーバを借りる。ハウジングは事業者の施設の場所・電源・回線だけを借り、自社のサーバを置く。 |
| **SOA** | **EAI** | SOAは業務機能をサービス部品にして組み合わせる設計思想。EAIは既存の複数アプリケーションをミドルウェアで連携・統合する手法。 |
| **COBIT** | **ITIL** | COBITはITガバナンス・統制の目標を定めるフレームワーク。ITILはITサービスマネジメントの実践方法（ベストプラクティス）集。 |
| **システム管理基準** | **COBIT** | システム管理基準は経済産業省が定めた日本の組織向けのIT管理の規範。COBITはISACAが策定した国際的なITガバナンスのフレームワーク。 |
| **デジタル経営改革のための評価指標（DX推進指標）** | **DX認定制度** | DX推進指標は企業が自らの取組状況を自己診断する指標。DX認定制度はデジタルガバナンス・コードの基本的事項に対応した事業者を国が認定する制度。 |
