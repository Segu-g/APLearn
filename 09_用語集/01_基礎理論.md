## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **桁落ち** | **情報落ち** | 桁落ちは値がほぼ等しい2数の差で有効桁数が減る誤差。情報落ちは絶対値の大きく違う数の加減算で、小さい方の値が結果に反映されない誤差。 |
| **丸め誤差** | **打切り誤差** | 丸め誤差は桁数に収めるための四捨五入・切捨てで生じる。打切り誤差は無限に続く計算を途中で止めたことで生じる。 |
| **論理シフト** | **算術シフト** | 論理シフトは符号を考えず空いたビットに0を入れる。算術シフトは符号ビットを保ち、右シフトでは符号ビットと同じ値を補う。 |
| **排他的論理和** | **否定排他的論理和（等価演算）** | XOR は2つの値が異なるときに1、等価演算（XNOR）は等しいときに1。互いに相補演算の関係。 |
| **否定論理積** | **否定論理和** | NAND は両方1のときだけ0、NOR は両方0のときだけ1。どちらも単独で全ての論理回路を作れる。 |
| **教師あり学習** | **教師なし学習** | 教師ありは正解ラベル付きデータで学び回帰・分類に使う。教師なしは正解なしでクラスタリングや次元削減を行う。 |
| **適合率（Precision）** | **再現率（Recall）** | 適合率は陽性と予測したもののうち本当に陽性の割合（誤検知を嫌う）。再現率は実際の陽性のうち陽性と予測できた割合（見逃しを嫌う）。 |
| **ROC 曲線** | **PR 曲線** | ROC 曲線は横軸 偽陽性率・縦軸 真陽性率。PR 曲線は横軸 再現率・縦軸 適合率で、陽性が少ない不均衡データの評価に向く。 |
| **検証データ** | **テストデータ** | 検証データはハイパーパラメータ調整やモデル選択に使う。テストデータは最終的な性能評価だけに使い、調整には使わない。 |
| **ファインチューニング** | **プロンプトエンジニアリング** | ファインチューニングは追加のデータで学習させてモデル自体を変える。プロンプトエンジニアリングはモデルを変えず指示文を工夫する。 |
| **二分法** | **ニュートン法** | 二分法は符号が変わる区間を半分ずつ狭める（遅いが確実）。ニュートン法は接線と x 軸の交点を次の近似値にする（速いが初期値次第で収束しない）。 |
| **主成分分析** | **因子分析** | 主成分分析は多数の変数を少数の合成変数に要約する。因子分析は観測変数の背後にある共通の潜在因子を推定する。 |
| **第1種の誤り** | **第2種の誤り** | 第1種は帰無仮説が正しいのに棄却する誤り（確率 α）。第2種は帰無仮説が誤りなのに棄却しない誤り（確率 β）。 |
| **CRC** | **ハミング符号** | CRC は生成多項式による誤り検出のみで訂正はしない（バースト誤りに強い）。ハミング符号は1ビットの誤りを訂正できる。 |
| **フィードバック制御** | **フィードフォワード制御** | フィードバック制御は出力を測って目標値との差を修正する（事後対応）。フィードフォワード制御は外乱を検知して影響が出る前に補正する（事前対応）。 |
