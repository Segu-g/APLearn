## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **デジタルツイン** | **サイバーフィジカルシステム（CPS）** | デジタルツインは現実の対象を仮想空間に再現してシミュレーションする技術。CPSはそれも含め、仮想空間での分析結果を現実世界にフィードバックして制御するループ全体を指す。 |
| **エッジコンピューティング** | **エッジAI** | エッジコンピューティングは端末の近くでデータ処理全般を行う方式。エッジAIはそのうち、学習済みモデルによるAIの推論を機器側で行うもの。 |
| **かんばん方式** | **JIT（ジャストインタイム）** | JITは必要なものを必要なときに必要な量だけ作るという考え方。かんばん方式は後工程が必要な分だけ引き取ることでJITを実現する具体的な手段。 |
| **受注生産** | **見込み生産** | 受注生産は注文を受けてから作る（在庫リスク小・納期長）。見込み生産は需要を予測して先に作り在庫を持つ（納期短・在庫リスク大）。 |
| **ファブレス** | **ファウンドリ** | ファブレスは工場を持たず設計・販売に特化し製造を委託する側。ファウンドリは他社から半導体の製造だけを請け負う側。 |
| **ファブレス** | **EMS（電子機器受託製造サービス）** | ファブレスは製造を外部に委託する側の企業。EMSは電子機器の製造を他社から受託する側の企業・サービス。 |
| **ERP** | **SCM** | ERPは1社内の基幹業務（生産・販売・会計・人事など）を統合管理する。SCMは企業の枠を越えて調達〜生産〜物流〜販売の流れを最適化する。 |
| **PDM** | **FMS** | PDMは図面・部品構成など設計・開発の製品データを一元管理するシステム。FMSはNC工作機械や搬送装置を統合制御して多品種少量生産に対応する生産設備のシステム。 |
| **CAD** | **CAM** | CADは設計（図面作成）の支援。CAMはCADの設計データからNC工作機械の加工データを作るなど製造の支援。 |
| **MES（製造実行システム）** | **PLC（プログラマブルロジックコントローラー）** | MESは工場の実行層で作業指示・進捗・品質を管理するシステム。PLCは制御層で機械をシーケンス制御する装置。 |
| **OtoO** | **OMO** | OtoOはネット上のクーポンなどで実店舗へ送客する施策。OMOはオンラインとオフラインを区別せず融合した顧客体験として設計する考え方。 |
| **アグリゲーションサービス** | **アカウントアグリゲーション** | アグリゲーションサービスは分散した事業者・サービスへの一括アクセスを提供するサービス全般。アカウントアグリゲーションはそのうち、複数の金融機関の口座情報をまとめて表示するもの。 |
| **暗号資産** | **電子マネー** | 暗号資産は不特定の者に使え法定通貨と交換できる財産的価値（資金決済法）。電子マネーは発行者が残高を管理し、加盟店などで使う前払式などの支払手段。 |
| **情報表現規約** | **情報伝達規約** | 情報表現規約はEDIで交換するメッセージの形式やコードを定める。情報伝達規約は通信回線や伝送制御手順など送受信の方法を定める。 |
| **AMR** | **AGV** | AMRはセンサーと地図で自ら経路を決めて走る自律走行搬送ロボット。AGVは磁気テープなど決められた経路に沿って走る無人搬送車。 |
