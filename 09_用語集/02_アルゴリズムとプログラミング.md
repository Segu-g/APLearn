## まぎらわしい用語

| 用語 | 用語 | 違い |
|---|---|---|
| **スタック** | **キュー** | スタックは最後に入れたものから取り出す（LIFO）、キューは最初に入れたものから取り出す（FIFO）。深さ優先探索はスタック、幅優先探索はキューで実現する。 |
| **深さ優先探索** | **幅優先探索** | 深さ優先は行けるところまで進んでから戻る（スタック・再帰）。幅優先は出発点に近い段から順に調べる（キュー）。 |
| **先行順** | **後行順** | 先行順は節を子より先（節→左→右）、後行順は子の後（左→右→節）に出力する。式の木なら先行順が前置記法、後行順が逆ポーランド記法。 |
| **2分探索木** | **ヒープ（木構造）** | 2分探索木は「左 < 節 < 右」で中間順に読むと昇順。ヒープは「親 ≧ 子」だけで左右の大小は決まらず、根が最大（最小）。 |
| **ヒープ（木構造）** | **ヒープ領域** | ヒープ（木構造）は親子の大小関係を保つ完全2分木。ヒープ領域は実行中に動的に確保・解放する記憶域で、名前が同じだけで別物。 |
| **線形探索法** | **2分探索法** | 線形探索は整列不要で O(n)（平均 約n/2回）。2分探索は整列済みが前提で O(log n)（最大 ⌊log₂n⌋＋1回）。 |
| **バブルソート** | **選択ソート** | バブルソートは隣どうしを比べて交換を繰り返す（安定）。選択ソートは最小値を探して先頭と1回交換する（不安定）。どちらも O(n²)。 |
| **クイックソート** | **マージソート** | どちらも分割統治法。クイックソートは基準値で分けてから整列し、最悪 O(n²)・不安定。マージソートは分けた後に併合し、最悪でも O(n log n)・安定。 |
| **ダイクストラ法** | **ベルマンフォード法** | ダイクストラ法は距離最小の頂点を順に確定させ高速だが負の重みは扱えない。ベルマンフォード法は全辺の更新を繰り返し、負の重みも扱える。 |
| **オーバーライド** | **オーバーロード** | オーバーライドは継承したメソッドを子クラスで同じ名前・同じ引数で再定義する。オーバーロードは同じ名前で引数の型・個数が違うメソッドを並べて定義する。 |
| **値呼出し** | **参照呼出し** | 値呼出しは値のコピーを渡すので呼出し元の変数は変わらない。参照呼出しは格納場所を渡すので、手続内の変更が呼出し元に反映される。 |
| **仮引数** | **実引数** | 仮引数は手続の定義側で値を受け取る変数（f(x) の x）、実引数は呼出し側で実際に渡す値（f(5) の 5）。 |
| **DOM** | **SAX** | DOM は文書全体を木構造でメモリに展開し自由に操作できる（メモリ大）。SAX は先頭から読みイベントごとに処理する（省メモリ、後戻り不可）。 |
| **クラス図** | **オブジェクト図** | クラス図はクラスどうしの静的な関係（型の設計図）、オブジェクト図はある時点のインスタンスどうしのつながり（具体例）を表す。 |
| **アクティビティ図** | **シーケンス図** | アクティビティ図は処理・業務の流れ（分岐・並行処理）を、シーケンス図はオブジェクト間のメッセージを時間順に表す。状態の変化を表すのはステートマシン図。 |
